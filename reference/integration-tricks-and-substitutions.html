Step-by-Step Evaluation of Taylor’s Cycloid Substitution

The integral to evaluate from Equation (6.23) is: \[x = \int \sqrt{\frac{y}{2a - y}} \, dy\]

Taylor introduces the substitution: \[y = a(1 - \cos\theta)\]

1. Differential of the Substitution

Differentiating \(y\) with respect to \(\theta\): \[dy = \frac{d}{d\theta}\big[a(1 - \cos\theta)\big] d\theta = a\sin\theta \, d\theta\] Using the double-angle identity \(\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)\): \[dy = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\]

2. Simplifying the Radicand

Substitute \(y = a(1 - \cos\theta)\) into the numerator and denominator under the radical: Numerator: \[y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right)\] Denominator: \[2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right)\] Taking the ratio inside the square root: \[\frac{y}{2a - y} = \frac{2a\sin^2\left(\frac{\theta}{2}\right)}{2a\cos^2\left(\frac{\theta}{2}\right)} = \tan^2\left(\frac{\theta}{2}\right)\] Assuming the motion stays within the first arch (\(\theta \in [0, 2\pi]\) where \(\theta/2 \in [0, \pi]\) and \(\sin(\theta/2) \ge 0\)): \[\sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\]

3. Combining and Integrating

Multiply the simplified radical by \(dy\): \[\sqrt{\frac{y}{2a - y}} \, dy = \left(\frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta\] Recall the half-angle identity \(2\sin^2\left(\frac{\theta}{2}\right) = 1 - \cos\theta\): \[x = \int a(1 - \cos\theta) \, d\theta = a(\theta - \sin\theta) + C\] Applying the initial condition \(x(0) = 0\) gives \(C = 0\), recovering the cycloid parametric equations: \[x = a(\theta - \sin\theta), \quad y = a(1 - \cos\theta)\]

Why That Substitution Works: The Hidden Circle

Taylor calls this an “unlikely looking substitution,” but it is completely systematic. Rationalize the numerator of the integrand: \[\sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}}\] Complete the square in the denominator: \[2ay - y^2 = -(y^2 - 2ay + a^2) + a^2 = a^2 - (y - a)^2\] Now the integral becomes: \[\int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy\] Any integral containing \(\sqrt{a^2 - u^2}\) calls for the standard circle substitution \(u = a\sin\phi\) or \(u = -a\cos\theta\). Setting: \[y - a = -a\cos\theta \implies y = a(1 - \cos\theta)\] The “clever” substitution is simply the standard trigonometric substitution for a circle of radius \(a\) centered at \((0, a)\).

The Algebraic Alternative: The Direct Root Substitution

You do not need to guess a trigonometric substitution. When faced with any rational function of a single linear radical \(\sqrt{\frac{a y + b}{c y + d}}\), set the entire radical equal to a new variable \(u\): \[u = \sqrt{\frac{y}{2a - y}}\] Invert for \(y\): \[u^2 = \frac{y}{2a - y} \implies u^2(2a - y) = y \implies 2a u^2 = y(1 + u^2) \implies y = \frac{2a u^2}{1 + u^2}\] Compute \(dy\): \[dy = 2a \frac{d}{du}\left[1 - \frac{1}{1 + u^2}\right] du = \frac{4a u}{(1 + u^2)^2} \, du\] Substitute into the integral: \[\int u \, dy = \int u \cdot \frac{4a u}{(1 + u^2)^2} \, du = 4a \int \frac{u^2}{(1 + u^2)^2} \, du\] Integrate by parts or standard trig: With \(u = \tan\phi\), this integral reduces directly to elementary trig integrals without guessing parameters in advance. So for algebraic integration use both trig and integration by parts.

Advanced Integration Tricks for Variational Physics

1. Euler’s First and Third Substitutions for \(\sqrt{Ax^2 + Bx + C}\)

When completing the square is cumbersome: - If \(A > 0\): Substitute \(\sqrt{Ax^2 + Bx + C} = \pm x\sqrt{A} + t\). Squaring both sides cancels \(Ax^2\), leaving \(x\) as a purely rational function of \(t\). - If the quadratic factors as \(A(x - r_1)(x - r_2)\): Substitute \(\sqrt{A(x - r_1)(x - r_2)} = t(x - r_1)\). Squaring eliminates the radical and rationalizes the entire expression.

2. The Weierstrass Tangent Half-Angle Substitution

For any integrand that is a rational function of \(\sin\theta\) and \(\cos\theta\): \[t = \tan\left(\frac{\theta}{2}\right) \implies \cos\theta = \frac{1 - t^2}{1 + t^2}, \quad \sin\theta = \frac{2t}{1 + t^2}, \quad d\theta = \frac{2}{1 + t^2} dt\] This maps any trigonometric integral into a rational polynomial integral solvable by partial fractions.

3. Hyperbolic Conversions for Catenaries and Relativistic Rapidity

Whenever you encounter forms like \(\int \frac{dy}{\sqrt{y^2 - y_0^2}}\) (as in the soap-film catenoid problem 6.19):

Instead of trigonometric secant substitution (\(y = y_0 \sec\theta\)), use the hyperbolic cosine: \[y = y_0 \cosh u \implies dy = y_0 \sinh u \, du\] \[\int \frac{y_0 \sinh u \, du}{\sqrt{y_0^2(\cosh^2 u - 1)}} = \int \frac{y_0 \sinh u}{y_0 \sinh u} \, du = \int du = u + C = \text{arcosh}\left(\frac{y}{y_0}\right) + C\] Inverting this immediately gives \(y(x) = y_0 \cosh\left(\frac{x - x_0}{y_0}\right)\) in one step without messy logarithms of absolute values.

Practice Problems for Speed Integration

Problem 1: The Normalized Fractional Root

\[\int_0^1 \sqrt{\frac{x}{1-x}} \, dx\]

Target Trick: The half-angle cycloid substitution (\(x = \sin^2\theta\)).

Speed-Round Solution: Let \(x = \sin^2\theta\), so \(dx = 2\sin\theta\cos\theta\, d\theta\). The bounds transform as \(0 \to 0\) and \(1 \to \pi/2\): \[\sqrt{\frac{x}{1-x}} = \sqrt{\frac{\sin^2\theta}{\cos^2\theta}} = \tan\theta\] Substitute directly into the integral: \[\int_0^{\pi/2} (\tan\theta) \cdot (2\sin\theta\cos\theta)\, d\theta = 2 \int_0^{\pi/2} \sin^2\theta\, d\theta\] Using the average value of \(\sin^2\theta\) over a quarter-period: \[2 \left(\frac{1}{2} \cdot \frac{\pi}{2}\right) = \mathbf{\frac{\pi}{2}}\]

Problem 2: The Factored Quadratic Surd

\[\int_0^1 \frac{dx}{(x+1)\sqrt{x(1-x)}}\]

Target Trick: Euler’s third substitution / factored root normalization.

Speed-Round Solution: Substitute \(x = \sin^2\theta\), giving \(dx = 2\sin\theta\cos\theta\, d\theta\) and \(\sqrt{x(1-x)} = \sin\theta\cos\theta\): \[\int_0^{\pi/2} \frac{2\sin\theta\cos\theta\, d\theta}{(1 + \sin^2\theta)\sin\theta\cos\theta} = \int_0^{\pi/2} \frac{2\, d\theta}{1 + \sin^2\theta}\] Divide numerator and denominator by \(\cos^2\theta\) to prepare an algebraic substitution: \[\int_0^{\pi/2} \frac{2\sec^2\theta}{\sec^2\theta + \tan^2\theta}\, d\theta = \int_0^{\pi/2} \frac{2\sec^2\theta}{1 + 2\tan^2\theta}\, d\theta\] Substitute \(u = \sqrt{2}\tan\theta\), so \(du = \sqrt{2}\sec^2\theta\, d\theta\), with limits \(0 \to \infty\): \[\int_0^\infty \frac{\sqrt{2}\, du}{1 + u^2} = \sqrt{2} \left[ \arctan(u) \right]_0^\infty = \sqrt{2}\left(\frac{\pi}{2}\right) = \mathbf{\frac{\pi}{\sqrt{2}}}\]

Problem 3: The 15-Second Weierstrass Benchmark

\[\int_0^{\pi/2} \frac{dx}{1 + \sin x + \cos x}\]

Target Trick: The classic half-angle substitution \(t = \tan(x/2)\).

Speed-Round Solution: Recall the rational identities: \[\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\, dt}{1+t^2}\] Combine the denominator terms: \[1 + \sin x + \cos x = \frac{(1+t^2) + 2t + (1-t^2)}{1+t^2} = \frac{2(1+t)}{1+t^2}\] The \((1+t^2)\) factors cancel against \(dx\): \[\int_0^1 \frac{\frac{2\, dt}{1+t^2}}{\frac{2(1+t)}{1+t^2}} = \int_0^1 \frac{dt}{1+t} = \left[ \ln(1+t) \right]_0^1 = \mathbf{\ln 2}\]

Problem 4: Inverse Factorization on \(\sqrt{x^2 - 1}\)

\[\int_1^2 \frac{\sqrt{x^2 - 1}}{x^4}\, dx\]

Target Trick: Direct radical factoring \(u = \sqrt{1 - x^{-2}}\) (bypassing trigonometric substitution).

Speed-Round Solution: Factor \(x\) out of the radical in the numerator: \[\frac{\sqrt{x^2-1}}{x^4} = \frac{x\sqrt{1 - x^{-2}}}{x^4} = \frac{\sqrt{1 - x^{-2}}}{x^3}\] Set \(u = \sqrt{1 - x^{-2}}\). Then \(u^2 = 1 - x^{-2} \implies 2u\, du = 2x^{-3}\, dx\), so: \[\frac{dx}{x^3} = u\, du\] The bounds transform from \(x \in [1, 2]\) to \(u \in \left[0, \frac{\sqrt{3}}{2}\right]\): \[\int_0^{\sqrt{3}/2} u \cdot (u\, du) = \int_0^{\sqrt{3}/2} u^2\, du = \left[ \frac{u^3}{3} \right]_0^{\sqrt{3}/2} = \frac{1}{3}\left(\frac{3\sqrt{3}}{8}\right) = \mathbf{\frac{\sqrt{3}}{8}}\]

Problem 5: Hyperbolic Shift with Inversion

\[\int_0^1 \frac{dx}{(x+1)\sqrt{x^2 + 2x + 2}}\]

Target Trick: Completing the square followed by inversion substitution \(u = 1/t\).

Speed-Round Solution: Complete the square inside the radical: \(x^2 + 2x + 2 = (x+1)^2 + 1\). Shift variables with \(y = x+1\): \[\int_1^2 \frac{dy}{y\sqrt{y^2 + 1}}\] Apply the inversion substitution \(y = \frac{1}{t}\), which gives \(dy = -\frac{dt}{t^2}\): \[\int_1^{1/2} \frac{-\frac{dt}{t^2}}{\frac{1}{t}\sqrt{\frac{1}{t^2} + 1}} = \int_{1/2}^1 \frac{dt}{\sqrt{1 + t^2}}\] Using the standard anti-derivative \(\int \frac{dt}{\sqrt{1+t^2}} = \operatorname{arsinh}(t) = \ln(t + \sqrt{t^2+1})\): \[\left[ \ln\left(t + \sqrt{t^2 + 1}\right) \right]_{1/2}^1 = \ln(1 + \sqrt{2}) - \ln\left(\frac{1 + \sqrt{5}}{2}\right) = \mathbf{\ln\left(\frac{2 + 2\sqrt{2}}{1 + \sqrt{5}}\right)}\]

# Step-by-Step Evaluation of Taylor's Cycloid Substitution

The integral to evaluate from Equation (6.23) is:
$$x = \int \sqrt{\frac{y}{2a - y}} \, dy$$

Taylor introduces the substitution:
$$y = a(1 - \cos\theta)$$

## 1. Differential of the Substitution
Differentiating $y$ with respect to $\theta$:
$$dy = \frac{d}{d\theta}\big[a(1 - \cos\theta)\big] d\theta = a\sin\theta \, d\theta$$
Using the double-angle identity $\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)$:
$$dy = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta$$

## 2. Simplifying the Radicand
Substitute $y = a(1 - \cos\theta)$ into the numerator and denominator under the radical:
Numerator:
$$y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right)$$
Denominator:
$$2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right)$$
Taking the ratio inside the square root:
$$\frac{y}{2a - y} = \frac{2a\sin^2\left(\frac{\theta}{2}\right)}{2a\cos^2\left(\frac{\theta}{2}\right)} = \tan^2\left(\frac{\theta}{2}\right)$$
Assuming the motion stays within the first arch ($\theta \in [0, 2\pi]$ where $\theta/2 \in [0, \pi]$ and $\sin(\theta/2) \ge 0$):
$$\sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}$$

## 3. Combining and Integrating
Multiply the simplified radical by $dy$:
$$\sqrt{\frac{y}{2a - y}} \, dy = \left(\frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta$$
Recall the half-angle identity $2\sin^2\left(\frac{\theta}{2}\right) = 1 - \cos\theta$:
$$x = \int a(1 - \cos\theta) \, d\theta = a(\theta - \sin\theta) + C$$
Applying the initial condition $x(0) = 0$ gives $C = 0$, recovering the cycloid parametric equations:
$$x = a(\theta - \sin\theta), \quad y = a(1 - \cos\theta)$$

Integrate by parts or standard trig:
With $u = \tan\phi$, this integral reduces directly to elementary trig integrals without guessing parameters in advance. *So for algebraic integration use both trig and integration by parts.*

# Advanced Integration Tricks for Variational Physics

## 1. Euler's First and Third Substitutions for $\sqrt{Ax^2 + Bx + C}$
When completing the square is cumbersome:
- **If $A > 0$:** Substitute $\sqrt{Ax^2 + Bx + C} = \pm x\sqrt{A} + t$. Squaring both sides cancels $Ax^2$, leaving $x$ as a purely rational function of $t$.
- **If the quadratic factors as $A(x - r_1)(x - r_2)$:** Substitute $\sqrt{A(x - r_1)(x - r_2)} = t(x - r_1)$. Squaring eliminates the radical and rationalizes the entire expression.

## 2. The Weierstrass Tangent Half-Angle Substitution
For any integrand that is a rational function of $\sin\theta$ and $\cos\theta$:
$$t = \tan\left(\frac{\theta}{2}\right) \implies \cos\theta = \frac{1 - t^2}{1 + t^2}, \quad \sin\theta = \frac{2t}{1 + t^2}, \quad d\theta = \frac{2}{1 + t^2} dt$$
This maps any trigonometric integral into a rational polynomial integral solvable by partial fractions.

## 3. Hyperbolic Conversions for Catenaries and Relativistic Rapidity
Whenever you encounter forms like $\int \frac{dy}{\sqrt{y^2 - y_0^2}}$ (as in the soap-film catenoid problem 6.19):

Instead of trigonometric secant substitution ($y = y_0 \sec\theta$), use the hyperbolic cosine:
$$y = y_0 \cosh u \implies dy = y_0 \sinh u \, du$$
$$\int \frac{y_0 \sinh u \, du}{\sqrt{y_0^2(\cosh^2 u - 1)}} = \int \frac{y_0 \sinh u}{y_0 \sinh u} \, du = \int du = u + C = \text{arcosh}\left(\frac{y}{y_0}\right) + C$$
Inverting this immediately gives $y(x) = y_0 \cosh\left(\frac{x - x_0}{y_0}\right)$ in one step without messy logarithms of absolute values.

# Practice Problems for Speed Integration

## Problem 1: The Normalized Fractional Root
$$\int_0^1 \sqrt{\frac{x}{1-x}} \, dx$$

**Target Trick:** The half-angle cycloid substitution ($x = \sin^2\theta$).

**Speed-Round Solution:**
Let $x = \sin^2\theta$, so $dx = 2\sin\theta\cos\theta\, d\theta$. The bounds transform as $0 \to 0$ and $1 \to \pi/2$:
$$\sqrt{\frac{x}{1-x}} = \sqrt{\frac{\sin^2\theta}{\cos^2\theta}} = \tan\theta$$
Substitute directly into the integral:
$$\int_0^{\pi/2} (\tan\theta) \cdot (2\sin\theta\cos\theta)\, d\theta = 2 \int_0^{\pi/2} \sin^2\theta\, d\theta$$
Using the average value of $\sin^2\theta$ over a quarter-period:
$$2 \left(\frac{1}{2} \cdot \frac{\pi}{2}\right) = \mathbf{\frac{\pi}{2}}$$

## Problem 2: The Factored Quadratic Surd
$$\int_0^1 \frac{dx}{(x+1)\sqrt{x(1-x)}}$$

**Target Trick:** Euler’s third substitution / factored root normalization.

**Speed-Round Solution:**
Substitute $x = \sin^2\theta$, giving $dx = 2\sin\theta\cos\theta\, d\theta$ and $\sqrt{x(1-x)} = \sin\theta\cos\theta$:
$$\int_0^{\pi/2} \frac{2\sin\theta\cos\theta\, d\theta}{(1 + \sin^2\theta)\sin\theta\cos\theta} = \int_0^{\pi/2} \frac{2\, d\theta}{1 + \sin^2\theta}$$
Divide numerator and denominator by $\cos^2\theta$ to prepare an algebraic substitution:
$$\int_0^{\pi/2} \frac{2\sec^2\theta}{\sec^2\theta + \tan^2\theta}\, d\theta = \int_0^{\pi/2} \frac{2\sec^2\theta}{1 + 2\tan^2\theta}\, d\theta$$
Substitute $u = \sqrt{2}\tan\theta$, so $du = \sqrt{2}\sec^2\theta\, d\theta$, with limits $0 \to \infty$:
$$\int_0^\infty \frac{\sqrt{2}\, du}{1 + u^2} = \sqrt{2} \left[ \arctan(u) \right]_0^\infty = \sqrt{2}\left(\frac{\pi}{2}\right) = \mathbf{\frac{\pi}{\sqrt{2}}}$$

## Problem 3: The 15-Second Weierstrass Benchmark
$$\int_0^{\pi/2} \frac{dx}{1 + \sin x + \cos x}$$

**Target Trick:** The classic half-angle substitution $t = \tan(x/2)$.

**Speed-Round Solution:**
Recall the rational identities:
$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\, dt}{1+t^2}$$
Combine the denominator terms:
$$1 + \sin x + \cos x = \frac{(1+t^2) + 2t + (1-t^2)}{1+t^2} = \frac{2(1+t)}{1+t^2}$$
The $(1+t^2)$ factors cancel against $dx$:
$$\int_0^1 \frac{\frac{2\, dt}{1+t^2}}{\frac{2(1+t)}{1+t^2}} = \int_0^1 \frac{dt}{1+t} = \left[ \ln(1+t) \right]_0^1 = \mathbf{\ln 2}$$

## Problem 4: Inverse Factorization on $\sqrt{x^2 - 1}$
$$\int_1^2 \frac{\sqrt{x^2 - 1}}{x^4}\, dx$$

**Target Trick:** Direct radical factoring $u = \sqrt{1 - x^{-2}}$ (bypassing trigonometric substitution).

**Speed-Round Solution:**
Factor $x$ out of the radical in the numerator:
$$\frac{\sqrt{x^2-1}}{x^4} = \frac{x\sqrt{1 - x^{-2}}}{x^4} = \frac{\sqrt{1 - x^{-2}}}{x^3}$$
Set $u = \sqrt{1 - x^{-2}}$. Then $u^2 = 1 - x^{-2} \implies 2u\, du = 2x^{-3}\, dx$, so:
$$\frac{dx}{x^3} = u\, du$$
The bounds transform from $x \in [1, 2]$ to $u \in \left[0, \frac{\sqrt{3}}{2}\right]$:
$$\int_0^{\sqrt{3}/2} u \cdot (u\, du) = \int_0^{\sqrt{3}/2} u^2\, du = \left[ \frac{u^3}{3} \right]_0^{\sqrt{3}/2} = \frac{1}{3}\left(\frac{3\sqrt{3}}{8}\right) = \mathbf{\frac{\sqrt{3}}{8}}$$

## Problem 5: Hyperbolic Shift with Inversion
$$\int_0^1 \frac{dx}{(x+1)\sqrt{x^2 + 2x + 2}}$$

**Target Trick:** Completing the square followed by inversion substitution $u = 1/t$.

**Speed-Round Solution:**
Complete the square inside the radical: $x^2 + 2x + 2 = (x+1)^2 + 1$. Shift variables with $y = x+1$:
$$\int_1^2 \frac{dy}{y\sqrt{y^2 + 1}}$$
Apply the inversion substitution $y = \frac{1}{t}$, which gives $dy = -\frac{dt}{t^2}$:
$$\int_1^{1/2} \frac{-\frac{dt}{t^2}}{\frac{1}{t}\sqrt{\frac{1}{t^2} + 1}} = \int_{1/2}^1 \frac{dt}{\sqrt{1 + t^2}}$$
Using the standard anti-derivative $\int \frac{dt}{\sqrt{1+t^2}} = \operatorname{arsinh}(t) = \ln(t + \sqrt{t^2+1})$:
$$\left[ \ln\left(t + \sqrt{t^2 + 1}\right) \right]_{1/2}^1 = \ln(1 + \sqrt{2}) - \ln\left(\frac{1 + \sqrt{5}}{2}\right) = \mathbf{\ln\left(\frac{2 + 2\sqrt{2}}{1 + \sqrt{5}}\right)}$$
