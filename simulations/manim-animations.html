Visualizing Classical Mechanics with Manim

This section provides Python animation scripts using the Manim Community Engine (originally created by Grant Sanderson / 3Blue1Brown) to animate mathematical physics theorems, coordinate transformations, phase space portraits, and Lagrangian dynamics.

1. Double Pendulum Chaos Animation (pendulum_scene.py)

The double pendulum is the quintessential demonstration of sensitive dependence on initial conditions (Hamiltonian chaos). Below is the complete Manim Python script used to render the motion and overlay the Lagrangian:

#| file: pendulum_scene.py
from manim import *
import numpy as np

class DoublePendulumScene(Scene):
    def construct(self):
        title = Title("Double Pendulum: Hamiltonian Chaos", color=BLUE_B)
        self.play(Write(title))

        # Origin pivot
        origin = UP * 1.5
        pivot = Dot(origin, color=WHITE, radius=0.08)

        # Pendulum parameters
        l1, l2 = 2.0, 1.8
        theta1, theta2 = 120 * DEGREES, -45 * DEGREES

        # Calculate coordinates
        p1 = origin + l1 * np.array([np.sin(theta1), -np.cos(theta1), 0])
        p2 = p1 + l2 * np.array([np.sin(theta2), -np.cos(theta2), 0])

        rod1 = Line(origin, p1, color=GRAY_B, stroke_width=4)
        rod2 = Line(p1, p2, color=GRAY_B, stroke_width=4)

        bob1 = Dot(p1, color=RED, radius=0.15)
        bob2 = Dot(p2, color=YELLOW, radius=0.15)

        self.play(FadeIn(pivot), Create(rod1), Create(rod2), GrowFromCenter(bob1), GrowFromCenter(bob2))
        self.wait(1)

        # Equations overlay
        lagrangian = MathTex(
            r"\mathcal{L} = \frac{1}{2}(m_1+m_2)l_1^2\dot{\theta}_1^2 + \frac{1}{2}m_2 l_2^2\dot{\theta}_2^2 + m_2 l_1 l_2 \dot{\theta}_1\dot{\theta}_2 \cos(\theta_1-\theta_2) - V(\theta_1, \theta_2)",
            font_size=28
        ).to_edge(DOWN)

        self.play(Write(lagrangian))
        self.wait(2)

CLI Rendering Commands

To render this scene with the Manim CLI:

# Preview in low quality (480p 15fps) for rapid iteration:
manim -pql simulations/pendulum_scene.py DoublePendulumScene

# Render final production video in 1080p 60fps:
manim -pqh simulations/pendulum_scene.py DoublePendulumScene

# Render in 4K resolution (2160p 60fps):
manim -pqk simulations/pendulum_scene.py DoublePendulumScene

3. Real-Time Interactive Canvas Simulation

Below is a live in-browser preview simulating the animation frame rendered directly via Observable JavaScript and HTML5 Canvas:

Code 
viewof speed = Inputs.range([0.2, 3.0], {value: 1.0, step: 0.1, label: "Playback Speed"})
Code 
manimCanvas = {
  const width = 560;
  const height = 300;
  const ctx = DOM.context2d(width, height);
  let t = 0;

  function draw() {
    t += 0.03 * speed;
    ctx.fillStyle = "#0f172a";
    ctx.fillRect(0, 0, width, height);

    const cx = width / 2;
    const cy = 50;
    const l1 = 85;
    const l2 = 75;

    const th1 = Math.sin(t) * 1.2;
    const th2 = Math.sin(t * 1.35 + 0.4) * 1.5;

    const x1 = cx + l1 * Math.sin(th1);
    const y1 = cy + l1 * Math.cos(th1);

    const x2 = x1 + l2 * Math.sin(th2);
    const y2 = y1 + l2 * Math.cos(th2);

    // Grid lines
    ctx.strokeStyle = "rgba(255,255,255,0.06)";
    for (let x = 0; x < width; x += 40) {
      ctx.beginPath(); ctx.moveTo(x, 0); ctx.lineTo(x, height); ctx.stroke();
    }
    for (let y = 0; y < height; y += 40) {
      ctx.beginPath(); ctx.moveTo(0, y); ctx.lineTo(width, y); ctx.stroke();
    }

    // Pivot
    ctx.fillStyle = "#ffffff";
    ctx.beginPath(); ctx.arc(cx, cy, 4, 0, 2*Math.PI); ctx.fill();

    // Rods
    ctx.strokeStyle = "#38bdf8";
    ctx.lineWidth = 3;
    ctx.beginPath();
    ctx.moveTo(cx, cy); ctx.lineTo(x1, y1); ctx.lineTo(x2, y2);
    ctx.stroke();

    // Bobs
    ctx.fillStyle = "#0284c7";
    ctx.beginPath(); ctx.arc(x1, y1, 8, 0, 2*Math.PI); ctx.fill();

    ctx.fillStyle = "#f43f5e";
    ctx.beginPath(); ctx.arc(x2, y2, 10, 0, 2*Math.PI); ctx.fill();

    ctx.fillStyle = "#94a3b8";
    ctx.font = "12px monospace";
    ctx.fillText("Interactive Manim Canvas Engine (Live Physics Simulation)", 16, height - 16);
  }

  const interval = d3.interval(draw, 25);
  invalidation.then(() => interval.stop());
  return ctx.canvas;
}
