Introduction to the Calculus of Variations

In classical mechanics, we often encounter problems where we need to find a path or a function that minimizes (or maximizes) a certain quantity. This is the domain of the Calculus of Variations. While ordinary calculus deals with finding points that extremize a function \(y = f(x)\), the calculus of variations deals with finding functions \(y(x)\) that extremize a functional (a function of a function), often expressed as an integral:

\[ S = \int_{x_1}^{x_2} f(y, y', x) \, dx \]

Two main classes of problems require this approach: 1. Symmetries make non-Cartesian coordinates (spherical, cylindrical) advantageous. 2. Constraints make it best to choose generalized coordinates (e.g., a particle on a sphere).

To transition to these generalized coordinates, Lagrangian mechanics provides a powerful framework built entirely on the calculus of variations and Hamilton’s Principle of Least Action.

6.1 Two Examples

The calculus of variations involves finding the minimum or maximum of a quantity that is expressible as an integral. To see how this can arise, let’s start with two simple, concrete examples.

The Shortest Path between Two Points

What is the shortest path between two points \((x_1, y_1)\) and \((x_2, y_2)\) in a plane? Let the path be given by a function \(y = y(x)\). An infinitesimal element of length along the path is \(ds = \sqrt{dx^2 + dy^2} = \sqrt{1 + (y')^2} \, dx\), where \(y' = dy/dx\).

The total length of the path is the integral: \[ L = \int_{x_1}^{x_2} \sqrt{1 + [y'(x)]^2} \, dx \]

The goal is to find the function \(y(x)\) that minimizes \(L\).

(See Problem 6.1)

Fermat’s Principle

A similar problem is to find the path that light will follow between two points. Fermat’s principle states that the path taken by light is the one for which the time of travel is minimum (or more precisely, stationary). The time to travel a short distance \(ds\) is \(ds/v\), where \(v = c/n(x,y)\) is the speed of light in a medium with refractive index \(n(x,y)\). The total time is: \[ t = \int_1^2 \frac{ds}{v} = \frac{1}{c} \int_{x_1}^{x_2} n(x, y) \sqrt{1 + (y')^2} \, dx \] As with the shortest path, we seek a function \(y(x)\) that makes this integral stationary. In elementary calculus, a point where \(df/dx = 0\) can be a maximum, minimum, or neither. Similarly, in the calculus of variations, making an integral stationary means an infinitesimal variation of the path leaves the integral unchanged, though it doesn’t guarantee a strict minimum.

6.2 The Euler-Lagrange Equation

Both examples above involve an integral of the form: \[ S[y] = \int_{x_1}^{x_2} f(y, y', x) \, dx \] where \(S\) is a functional. We want to find the path \(y(x)\) that makes \(S\) stationary (a minimum, maximum, or saddle point).

Derivation

Let the actual path that extremizes the integral be \(y(x)\). Consider a “wrong” path \(Y(x)\) that is close to \(y(x)\). We can parameterize this wrong path as: \[ Y(x) = y(x) + \alpha \eta(x) \] where \(\alpha\) is a small parameter, and \(\eta(x)\) is an arbitrary differentiable function representing the variation. Since all paths must start at \(x_1\) and end at \(x_2\), the variation must vanish at the endpoints: \[ \eta(x_1) = \eta(x_2) = 0 \]

The integral evaluated along the varied path is a function of \(\alpha\): \[ S(\alpha) = \int_{x_1}^{x_2} f(Y, Y', x) \, dx = \int_{x_1}^{x_2} f(y + \alpha \eta, y' + \alpha \eta', x) \, dx \]

For the integral to be stationary at the correct path \(y(x)\), the derivative of \(S\) with respect to \(\alpha\) must be zero when \(\alpha = 0\): \[ \left. \frac{dS}{d\alpha} \right|_{\alpha=0} = 0 \]

Using the chain rule to differentiate inside the integral: \[ \frac{dS}{d\alpha} = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \frac{\partial Y}{\partial \alpha} + \frac{\partial f}{\partial Y'} \frac{\partial Y'}{\partial \alpha} \right) dx = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \eta + \frac{\partial f}{\partial Y'} \eta' \right) dx \]

Set \(\alpha = 0\), so \(Y \to y\) and \(Y' \to y'\): \[ \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial y} \eta(x) + \frac{\partial f}{\partial y'} \eta'(x) \right) dx = 0 \]

We integrate the second term by parts: \[ \int_{x_1}^{x_2} \frac{\partial f}{\partial y'} \eta'(x) \, dx = \left[ \frac{\partial f}{\partial y'} \eta(x) \right]_{x_1}^{x_2} - \int_{x_1}^{x_2} \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \eta(x) \, dx \]

Since \(\eta(x_1) = \eta(x_2) = 0\), the boundary term vanishes. The condition becomes: \[ \int_{x_1}^{x_2} \left[ \frac{\partial f}{\partial y} - \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \right] \eta(x) \, dx = 0 \]

For this to hold for any arbitrary variation \(\eta(x)\), the term in the brackets must be identically zero. This yields the Euler-Lagrange Equation:

\[ \frac{\partial f}{\partial y} - \frac{d}{dx} \frac{\partial f}{\partial y'} = 0 \]

6.3 Applications of the Euler-Lagrange Equation

Example 6.1: Shortest Path between Two Points

For the shortest path, \(f(y, y', x) = \sqrt{1 + y'^2}\). Since \(\partial f / \partial y = 0\), the E-L equation reduces to: \[ \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) = 0 \implies \frac{\partial f}{\partial y'} = C \] \[ \frac{y'}{\sqrt{1 + y'^2}} = C \implies y'^2 = C^2(1 + y'^2) \implies y'^2 = \frac{C^2}{1-C^2} = m^2 \] Thus, \(y' = m\), meaning \(y = mx + b\). The shortest path is a straight line.

A Note on Variables

So far we have used \(x\) as the independent variable and \(y\) as the dependent variable. In mechanics, the independent variable is usually time \(t\), and the dependent variable is position \(x(t)\). Sometimes, as in the next example, it is more convenient to use \(y\) as the independent variable and \(x(y)\) as the dependent variable.

Example 6.2: The Brachistochrone

First posed by Johann Bernoulli in 1696. Given two points 1 and 2, with 1 higher than 2, what is the shape of a frictionless wire connecting them such that a bead released from rest at 1 slides to 2 in the minimum possible time?

Let point 1 be the origin \((0,0)\). We take the \(y\)-axis pointing downward. The speed of the bead is \(v = ds/dt\). By conservation of energy, \(E = T + U\). If released from rest at \((0,0)\), \(E = 0\). \[ \frac{1}{2}mv^2 - mgy = 0 \implies v = \sqrt{2gy} \]

The time to travel an infinitesimal distance \(ds\) is \(dt = ds/v\). The total time is: \[ t = \int_{1}^{2} \frac{ds}{v} = \int_{x_1}^{x_2} \frac{\sqrt{1 + (y')^2}}{\sqrt{2gy}} \, dx \]

We need to find the function \(y(x)\) that minimizes this time integral \(t\).

(See Problem 6.2)

Problem Formulation & The Beltrami Identity

For the Brachistochrone, the functional integrand is \(f(y, y') = \sqrt{\frac{1 + (y')^2}{y}}\) (dropping overall constants \(\sqrt{2g}\)).
Because \(f\) lacks explicit dependence on the independent variable \(x\) (\(\partial f / \partial x = 0\)), the Euler-Lagrange equation possesses a first integral known as the Beltrami Identity: \[ f - y' \frac{\partial f}{\partial y'} = C \]

Substituting \(f\): \[ \sqrt{\frac{1 + (y')^2}{y}} - y' \frac{y'}{\sqrt{y(1 + (y')^2)}} = C \] \[ \frac{1 + (y')^2 - (y')^2}{\sqrt{y(1 + (y')^2)}} = C \implies \frac{1}{\sqrt{y(1 + (y')^2)}} = C \implies y\big(1 + (y')^2\big) = \frac{1}{C^2} \equiv 2a \]

Solving for the derivative \(y' = dy/dx\): \[ y' = \sqrt{\frac{2a - y}{y}} \implies dx = \sqrt{\frac{y}{2a - y}} \, dy \]

The total trajectory \(x(y)\) is given by the integral: \[ x = \int \sqrt{\frac{y}{2a - y}} \, dy \]

Step-by-Step Evaluation of Taylor’s Cycloid Substitution

Taylor introduces the parameterized substitution: \[ y = a(1 - \cos\theta) \]

  1. Differential of the Substitution:
    Differentiating \(y\) with respect to \(\theta\): \[ dy = a\sin\theta \, d\theta = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta \]

  2. Simplifying the Radicand:
    Substitute \(y = a(1 - \cos\theta)\) into the numerator and denominator:

    • Numerator: \(y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right)\)
    • Denominator: \(2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right)\)

    Taking the ratio inside the square root: \[ \frac{y}{2a - y} = \frac{2a\sin^2(\theta/2)}{2a\cos^2(\theta/2)} = \tan^2\left(\frac{\theta}{2}\right) \] Assuming the motion stays within the first arch (\(\theta \in [0, 2\pi]\) where \(\theta/2 \in [0, \pi]\) and \(\sin(\theta/2) \ge 0\)): \[ \sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin(\theta/2)}{\cos(\theta/2)} \]

  3. Combining and Integrating:
    Multiplying the simplified radical by \(dy\): \[ dx = \left(\frac{\sin(\theta/2)}{\cos(\theta/2)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta = a(1 - \cos\theta) \, d\theta \] Integrating directly with initial condition \(x(0) = 0\) gives: \[ x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta) \] These are the parametric equations of a cycloid.

Mathematical & Physical Rationale for the First Arch (\(\theta \in [0, 2\pi]\))

  1. Mathematical Reason (Principal Square Root):
    The square root identity is \(\sqrt{u^2} = |u|\). Thus: \[ \sqrt{\tan^2(\theta/2)} = |\tan(\theta/2)| = \frac{|\sin(\theta/2)|}{|\cos(\theta/2)|} \] Within the first arch (\(\theta \in [0, 2\pi]\)), the half-angle satisfies \(\frac{\theta}{2} \in [0, \pi]\), where the sine function is unconditionally non-negative: \[ \sin\left(\frac{\theta}{2}\right) \ge 0 \implies \left|\sin\left(\frac{\theta}{2}\right)\right| = \sin\left(\frac{\theta}{2}\right) \] This eliminates piece-wise absolute value signs without ambiguity. Along the descending branch (\(\theta < \pi\)), \(\cos(\theta/2) > 0\) and \(dy > 0\). Past the trough (\(\theta > \pi\)), \(\cos(\theta/2) < 0\) while the particle ascends (\(dy < 0\)), maintaining consistent directional progress \(dx \ge 0\).

  2. Physical Reason (Energy Bounds & Uniqueness):

    • Energy Ceiling: By conservation of energy, \(v = \sqrt{2gy}\). At \(y = 0\), speed vanishes (\(v = 0\)). The bead cannot ascend into \(y < 0\), ensuring the trajectory cannot continue past the cusp at \(\theta = 2\pi\).
    • Path Uniqueness: By scaling the radius \(a\) and endpoint angle \(\theta_2 \in (0, 2\pi]\), a unique single cycloid arch connects the origin \((0, 0)\) to any target point \((x_2, y_2)\) with \(x_2 > 0, y_2 \ge 0\).
    • No Redundant Loops: Any path spanning into subsequent arches would entail climbing to a cusp, arresting, and falling through extra dips, adding superfluous travel time and violating \(\delta T = 0\).

Why That Substitution Works: The Hidden Circle

Taylor calls \(y = a(1 - \cos\theta)\) an “unlikely looking substitution,” but it is completely systematic.
Rationalizing the numerator: \[ \sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}} \] Completing the square in the denominator: \[ 2ay - y^2 = a^2 - (y - a)^2 \implies \int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy \]

Geometric Origin:
The expression \(\sqrt{a^2 - (y - a)^2}\) describes a semicircle \((y - a)^2 + w^2 = a^2\) of radius \(a\) centered at \((0, a)\).

Dual Circle Parameterizations:
Any form \(\sqrt{a^2 - u^2}\) permits two standard circular substitutions: 1. Sine substitution (\(u = a\sin\phi\)): Setting \(y - a = a\sin\phi \implies y = a(1 + \sin\phi)\). At the release point \(y = 0\), \(\sin\phi = -1 \implies \phi = -\pi/2\), imposing an unwanted phase shift. 2. Inverted cosine substitution (\(u = -a\cos\theta\)): Setting \(y - a = -a\cos\theta \implies y = a(1 - \cos\theta)\). At release (\(y = 0\)), \(\cos(0) = 1 \implies \theta = 0\), matching initial rest conditions at the origin with zero phase offset!

The Algebraic Alternative: Direct Root Substitution

Rather than guessing a trigonometric form, set the entire linear radical equal to an algebraic variable \(u\): \[ u = \sqrt{\frac{y}{2a - y}} \implies y = \frac{2a u^2}{1 + u^2}, \quad dy = \frac{4a u}{(1 + u^2)^2} \, du \] The integral becomes: \[ x = \int u \, dy = 4a \int \frac{u^2}{(1 + u^2)^2} \, du \]

This can be evaluated via two direct methods:

Method A: Integration by Parts (Pure Algebraic Route)

Decomposing as \(u \cdot \frac{u}{(1 + u^2)^2}\) with \(f = u\) and \(dg = \frac{u}{(1 + u^2)^2}du \implies g = -\frac{1}{2(1 + u^2)}\): \[ \int \frac{u^2}{(1 + u^2)^2} \, du = -\frac{u}{2(1 + u^2)} + \frac{1}{2}\int \frac{du}{1 + u^2} = -\frac{u}{2(1 + u^2)} + \frac{1}{2}\arctan(u) \] Multiplying by \(4a\) and enforcing \(x(0) = 0\): \[ x(u) = 2a\arctan(u) - \frac{2a u}{1 + u^2} \] Setting \(u = \tan(\theta/2)\), we find \(\arctan(u) = \theta/2\) and \(\frac{2u}{1 + u^2} = \sin\theta\), which directly recovers: \[ x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta) \]

Method B: Trigonometric Substitution

Substituting \(u = \tan\phi\) with \(du = \sec^2\phi \, d\phi\): \[ 4a \int \frac{\tan^2\phi}{\sec^4\phi}\sec^2\phi \, d\phi = 4a \int \sin^2\phi \, d\phi = 2a(\phi - \sin\phi\cos\phi) \] Setting \(\theta = 2\phi\) immediately produces \(x = a(\theta - \sin\theta)\).

Essential Mathematical Properties of Cycloids

  • Parametric Equations: \(x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta)\)
  • Differential Arc Length: \[ ds = \sqrt{\dot{x}^2 + \dot{y}^2} \, d\theta = 2a\sin\left(\frac{\theta}{2}\right) d\theta \]
  • Cumulative Arc Length from Origin: \[ s(\theta) = \int_0^\theta 2a\sin\left(\frac{\theta'}{2}\right) d\theta' = 4a\left(1 - \cos\left(\frac{\theta}{2}\right)\right) = 8a\sin^2\left(\frac{\theta}{4}\right) \] A full single arch (\(\theta = 2\pi\)) has total perimeter \(s_{\text{total}} = 8a\).
  • Radius of Curvature: \[ \rho(\theta) = 4a\sin\left(\frac{\theta}{2}\right) = \sqrt{8a y} \]
  • Self-Evolute Property: The evolute of a cycloid is an identical cycloid shifted horizontally by \(\pi a\) and downward by \(2a\).

Maximum and Minimum vs. Stationary

You have probably noticed that we haven’t rigorously checked if the cycloid gives a true minimum time, as opposed to a maximum or saddle point. For instance, the geodesic between two points on a globe is a great circle. While the shortest path is a great circle, the long way around the globe on the same great circle is also a stationary path, but it is neither a minimum nor a maximum (it’s a saddle point).

⚠️ Stationary Action vs. “Least” Action in Physics

A common conceptual question in variational calculus and classical mechanics is: Does the physical trajectory minimize, maximize, or merely make the action stationary? And why is this distinction almost entirely ignored in classical mechanics?

1. Why the Distinction is Irrelevant for Classical Mechanics

Hamilton’s principle states that the true physical trajectory satisfies: \[ \delta S = 0 \quad \text{where} \quad S[q] = \int_{t_1}^{t_2} L(q, \dot{q}, t) \, dt \] The derivation of the Euler-Lagrange equations—and therefore Newton’s second law \(\mathbf{F} = m\mathbf{a}\)—rests entirely and exclusively on the vanishing of the first variation (\(\delta S = 0\)). * The dynamical equations of motion are local in time differential equations. * A particle propagating along a trajectory does not “anticipate” or “calculate” the global second variation \(\delta^2 S\) across the whole time interval \([t_1, t_2]\). * Whether \(\delta^2 S > 0\) (local minimum), \(\delta^2 S < 0\) (local maximum), or \(\delta^2 S\) is indefinite (saddle point) has zero impact on whether the path satisfies \(\frac{\partial L}{\partial q} - \frac{d}{dt}\frac{\partial L}{\partial \dot{q}} = 0\).

Historically, Maupertuis and Euler dubbed this the “Principle of Least Action”, believing nature operates with divine economy. However, calling it “least” action is a historical misnomer. In fact, for sufficiently long trajectories, true physical paths are almost never global minima—they are saddle points. Hence, modern physics refers to it strictly as the Principle of Stationary Action.

(Note: In static equilibrium, \(\delta V = 0\) gives equilibrium, but \(\delta^2 V > 0\) is indeed required for stability. But for dynamical trajectories, stationarity is all that mechanics requires.)

2. Where and When Does Min vs. Max vs. Saddle Point Matter?

While ordinary classical trajectories require only \(\delta S = 0\), distinguishing the character of the stationary point becomes critical in several advanced domains:

  1. Gravitational Lensing & Fermat’s Principle (Geometrical Optics): Light rays follow paths of stationary travel time (\(\delta t = 0\)). When a massive galaxy or cluster gravitationally lenses a background quasar, the light travel-time surface \(t(\boldsymbol{\theta})\) has multiple stationary points:

    • Local Minima: Arrive first, produce bright, positive-parity images (Type I).
    • Saddle Points: Arrive second, produce inverted, negative-parity images (Type II).
    • Local Maxima: Arrive last, located near the dense core of the lens galaxy, and are typically highly demagnified (Type III). The famous Odd Number Theorem in gravitational lensing relies directly on Morse theory characterizing these critical points!

  2. Quantum Mechanics & Feynman Path Integrals: In Feynman’s path integral formulation, the transition amplitude sums over all conceivable paths: \[ K(x_b, t_b; x_a, t_a) = \int \mathcal{D}[x(t)] \, e^{i S[x] / \hbar} \] In the classical limit \(\hbar \to 0\), paths with \(\delta S \ne 0\) experience destructive phase interference and cancel out, leaving the stationary path \(\delta S = 0\). However, the quantum fluctuations around the classical path are governed by the second variation \(\delta^2 S\):

    • The eigenvalues of the second-variation operator determine the Van Vleck determinant and phase shifts called the Maslov index. Every time a classical path passes through a focal/conjugate point, the quantum wavefunction acquires an extra phase shift of \(e^{-i\pi/2}\).

  3. Quantum Tunneling & Instanton Calculations: In Euclidean field theory (wick-rotated imaginary time \(\tau = it\)), the Euclidean action \(S_E\) governs false-vacuum decay and barrier penetration. A true physical “bounce” (instanton) that mediates tunneling must have precisely one negative eigenvalue in its second variation operator \(\delta^2 S_E\). That solitary negative mode is the mathematical signature of metastability!

  4. Spacetime Geodesics in General Relativity: For timelike worldlines of freely falling test particles between two events, the action is proportional to the proper time: \(S = -mc \int d\tau\). Here, free fall actually maximizes proper time locally (the twin paradox: the unaccelerated twin ages the most).

3. Why Is This Question in General Hard to Answer?

In single-variable calculus, determining whether \(f'(x_0) = 0\) is a min or max requires merely computing the single scalar second derivative \(f''(x_0)\).

In the calculus of variations, however, the action \(S[y]\) is a functional defined on an infinite-dimensional function space (the space of all differentiable paths \(\eta(x)\) satisfying \(\eta(x_1) = \eta(x_2) = 0\)). The second variation is a differential operator: \[ \delta^2 S = \frac{1}{2} \int_{x_1}^{x_2} \left[ P(x) (\eta')^2 + Q(x) \eta^2 \right] dx \] where \(P(x) = \frac{\partial^2 f}{\partial y'^2}\) and \(Q(x) = \frac{\partial^2 f}{\partial y^2} - \frac{d}{dx}\left(\frac{\partial^2 f}{\partial y \partial y'}\right)\).

Determining whether \(\delta^2 S > 0\) for all possible variations \(\eta(x)\) is difficult because:

  1. Legendre’s Condition is Only Necessary, Not Sufficient: The condition \(P(x) = \frac{\partial^2 f}{\partial y'^2} > 0\) ensures that very rapid, high-frequency wiggles (where \(\eta'\) dominates \(\eta\)) increase the action. But it tells you nothing about smooth, long-wavelength variations!
  2. Jacobi’s Condition & Conjugate Points: To verify a true local minimum, one must solve the Jacobi accessory differential equation: \[ \frac{d}{dx}\left( P(x) \frac{du}{dx} \right) - Q(x) u = 0 \] If there exists an intermediate point \(x^* \in (x_1, x_2)\)—called a conjugate point (or focal point)—where a non-trivial solution vanishes (\(u(x_1) = 0\) and \(u(x^*) = 0\)), then the path immediately ceases to be a minimum! Beyond the conjugate point, one can construct an envelope of variations for which \(\delta^2 S < 0\), turning the stationary path into a saddle point.
Concrete Example: The Simple Harmonic Oscillator

Consider a 1D harmonic oscillator with Lagrangian \(L = \frac{1}{2}m\dot{x}^2 - \frac{1}{2}m\omega^2 x^2\), starting at \(x(0) = 0\) and arriving at \(x(T) = 0\): * The stationary path is \(x(t) = 0\) for all \(t\). * The Legendre condition is \(P = \frac{\partial^2 L}{\partial \dot{x}^2} = m > 0\) (trivially satisfied). * Now evaluate the second variation for a variation \(\eta(t) = \sin(\pi t / T)\): \[ \delta^2 S = \frac{1}{2} \int_0^T \left[ m \left(\frac{\pi}{T}\right)^2 \cos^2\left(\frac{\pi t}{T}\right) - m\omega^2 \sin^2\left(\frac{\pi t}{T}\right) \right] dt = \frac{m T}{4} \left[ \left(\frac{\pi}{T}\right)^2 - \omega^2 \right] \] * Case 1 (\(T < \pi/\omega\), less than half a period): \(\left(\frac{\pi}{T}\right)^2 > \omega^2 \implies \delta^2 S > 0\). The path is a strict local minimum. * Case 2 (\(T = \pi/\omega\), exactly half a period): \(t^* = \pi/\omega\) is a conjugate point. At this point, infinitely many physical trajectories (all amplitudes \(A \sin(\omega t)\)) have the exact same action! * Case 3 (\(T > \pi/\omega\), more than half a period): \(\left(\frac{\pi}{T}\right)^2 < \omega^2 \implies \delta^2 S < 0\)! The action is a saddle point.

Yet throughout all three cases, the harmonic oscillator obeys the exact same physical laws of motion (\(\ddot{x} + \omega^2 x = 0\)) without any issue.

6.4 More Than Two Variables

If the functional depends on multiple functions \(y_1(x), y_2(x), \dots, y_n(x)\), \[ S = \int_{x_1}^{x_2} f(y_1, \dots, y_n, y_1', \dots, y_n', x) \, dx \] we can vary each function independently. This leads to a system of \(n\) independent Euler-Lagrange equations: \[ \frac{\partial f}{\partial y_i} - \frac{d}{dx} \frac{\partial f}{\partial y_i'} = 0 \quad \text{for } i = 1, 2, \dots, n \]

This extension is crucial for Lagrangian mechanics in 3D space, where we have coordinates \(x(t), y(t), z(t)\), and time \(t\) plays the role of the independent variable.

(See Problem 6.22)

Summary

The calculus of variations allows us to find stationary paths for functionals. The fundamental tool is the Euler-Lagrange equation, which converts a global variational problem into a local differential equation. This mathematical foundation is what allows us to formulate Lagrangian mechanics based on Hamilton’s Principle of stationary action.

# Introduction to the Calculus of Variations

In classical mechanics, we often encounter problems where we need to find a path or a function that minimizes (or maximizes) a certain quantity. This is the domain of the **Calculus of Variations**. While ordinary calculus deals with finding points that extremize a function $y = f(x)$, the calculus of variations deals with finding *functions* $y(x)$ that extremize a *functional* (a function of a function), often expressed as an integral:

$$ S = \int_{x_1}^{x_2} f(y, y', x) \, dx $$

Two main classes of problems require this approach:
1. Symmetries make non-Cartesian coordinates (spherical, cylindrical) advantageous.
2. Constraints make it best to choose generalized coordinates (e.g., a particle on a sphere).

To transition to these generalized coordinates, Lagrangian mechanics provides a powerful framework built entirely on the calculus of variations and Hamilton's Principle of Least Action.

## 6.1 Two Examples
The calculus of variations involves finding the minimum or maximum of a quantity that is expressible as an integral. To see how this can arise, let's start with two simple, concrete examples.

### The Shortest Path between Two Points

What is the shortest path between two points $(x_1, y_1)$ and $(x_2, y_2)$ in a plane? Let the path be given by a function $y = y(x)$. An infinitesimal element of length along the path is $ds = \sqrt{dx^2 + dy^2} = \sqrt{1 + (y')^2} \, dx$, where $y' = dy/dx$.

The total length of the path is the integral:
$$ L = \int_{x_1}^{x_2} \sqrt{1 + [y'(x)]^2} \, dx $$

The goal is to find the function $y(x)$ that minimizes $L$.

*(See [Problem 6.1](../solutions/taylor-chapter-6-problems.qmd#problem-61))*

### Fermat's Principle
A similar problem is to find the path that light will follow between two points. Fermat's principle states that the path taken by light is the one for which the time of travel is minimum (or more precisely, stationary).
The time to travel a short distance $ds$ is $ds/v$, where $v = c/n(x,y)$ is the speed of light in a medium with refractive index $n(x,y)$. The total time is:
$$ t = \int_1^2 \frac{ds}{v} = \frac{1}{c} \int_{x_1}^{x_2} n(x, y) \sqrt{1 + (y')^2} \, dx $$
As with the shortest path, we seek a function $y(x)$ that makes this integral stationary. In elementary calculus, a point where $df/dx = 0$ can be a maximum, minimum, or neither. Similarly, in the calculus of variations, making an integral stationary means an infinitesimal variation of the path leaves the integral unchanged, though it doesn't guarantee a strict minimum.

## 6.2 The Euler-Lagrange Equation

Both examples above involve an integral of the form:
$$ S[y] = \int_{x_1}^{x_2} f(y, y', x) \, dx $$
where $S$ is a functional. We want to find the path $y(x)$ that makes $S$ stationary (a minimum, maximum, or saddle point).

### Derivation

Let the actual path that extremizes the integral be $y(x)$. Consider a "wrong" path $Y(x)$ that is close to $y(x)$. We can parameterize this wrong path as:
$$ Y(x) = y(x) + \alpha \eta(x) $$
where $\alpha$ is a small parameter, and $\eta(x)$ is an arbitrary differentiable function representing the variation. Since all paths must start at $x_1$ and end at $x_2$, the variation must vanish at the endpoints:
$$ \eta(x_1) = \eta(x_2) = 0 $$

The integral evaluated along the varied path is a function of $\alpha$:
$$ S(\alpha) = \int_{x_1}^{x_2} f(Y, Y', x) \, dx = \int_{x_1}^{x_2} f(y + \alpha \eta, y' + \alpha \eta', x) \, dx $$

For the integral to be stationary at the correct path $y(x)$, the derivative of $S$ with respect to $\alpha$ must be zero when $\alpha = 0$:
$$ \left. \frac{dS}{d\alpha} \right|_{\alpha=0} = 0 $$

Using the chain rule to differentiate inside the integral:
$$ \frac{dS}{d\alpha} = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \frac{\partial Y}{\partial \alpha} + \frac{\partial f}{\partial Y'} \frac{\partial Y'}{\partial \alpha} \right) dx = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \eta + \frac{\partial f}{\partial Y'} \eta' \right) dx $$

Set $\alpha = 0$, so $Y \to y$ and $Y' \to y'$:
$$ \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial y} \eta(x) + \frac{\partial f}{\partial y'} \eta'(x) \right) dx = 0 $$

We integrate the second term by parts:
$$ \int_{x_1}^{x_2} \frac{\partial f}{\partial y'} \eta'(x) \, dx = \left[ \frac{\partial f}{\partial y'} \eta(x) \right]_{x_1}^{x_2} - \int_{x_1}^{x_2} \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \eta(x) \, dx $$

Since $\eta(x_1) = \eta(x_2) = 0$, the boundary term vanishes. The condition becomes:
$$ \int_{x_1}^{x_2} \left[ \frac{\partial f}{\partial y} - \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \right] \eta(x) \, dx = 0 $$

For this to hold for *any* arbitrary variation $\eta(x)$, the term in the brackets must be identically zero. This yields the **Euler-Lagrange Equation**:

$$ \frac{\partial f}{\partial y} - \frac{d}{dx} \frac{\partial f}{\partial y'} = 0 $$

*(See [Problem 6.4](../solutions/taylor-chapter-6-problems.qmd#problem-64))*

## 6.3 Applications of the Euler-Lagrange Equation

### Example 6.1: Shortest Path between Two Points
For the shortest path, $f(y, y', x) = \sqrt{1 + y'^2}$.
Since $\partial f / \partial y = 0$, the E-L equation reduces to:
$$ \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) = 0 \implies \frac{\partial f}{\partial y'} = C $$
$$ \frac{y'}{\sqrt{1 + y'^2}} = C \implies y'^2 = C^2(1 + y'^2) \implies y'^2 = \frac{C^2}{1-C^2} = m^2 $$
Thus, $y' = m$, meaning $y = mx + b$. The shortest path is a straight line.

### A Note on Variables
So far we have used $x$ as the independent variable and $y$ as the dependent variable. In mechanics, the independent variable is usually time $t$, and the dependent variable is position $x(t)$. Sometimes, as in the next example, it is more convenient to use $y$ as the independent variable and $x(y)$ as the dependent variable.


### Example 6.2: The Brachistochrone
First posed by Johann Bernoulli in 1696. Given two points 1 and 2, with 1 higher than 2, what is the shape of a frictionless wire connecting them such that a bead released from rest at 1 slides to 2 in the minimum possible time?

Let point 1 be the origin $(0,0)$. We take the $y$-axis pointing *downward*.
The speed of the bead is $v = ds/dt$. By conservation of energy, $E = T + U$. If released from rest at $(0,0)$, $E = 0$.
$$ \frac{1}{2}mv^2 - mgy = 0 \implies v = \sqrt{2gy} $$

The time to travel an infinitesimal distance $ds$ is $dt = ds/v$. The total time is:
$$ t = \int_{1}^{2} \frac{ds}{v} = \int_{x_1}^{x_2} \frac{\sqrt{1 + (y')^2}}{\sqrt{2gy}} \, dx $$

We need to find the function $y(x)$ that minimizes this time integral $t$.

*(See [Problem 6.2](../solutions/taylor-chapter-6-problems.qmd#problem-62))*

#### Problem Formulation & The Beltrami Identity

For the Brachistochrone, the functional integrand is $f(y, y') = \sqrt{\frac{1 + (y')^2}{y}}$ (dropping overall constants $\sqrt{2g}$).  
Because $f$ lacks explicit dependence on the independent variable $x$ ($\partial f / \partial x = 0$), the Euler-Lagrange equation possesses a first integral known as the **Beltrami Identity**:
$$ f - y' \frac{\partial f}{\partial y'} = C $$

Substituting $f$:
$$ \sqrt{\frac{1 + (y')^2}{y}} - y' \frac{y'}{\sqrt{y(1 + (y')^2)}} = C $$
$$ \frac{1 + (y')^2 - (y')^2}{\sqrt{y(1 + (y')^2)}} = C \implies \frac{1}{\sqrt{y(1 + (y')^2)}} = C \implies y\big(1 + (y')^2\big) = \frac{1}{C^2} \equiv 2a $$

Solving for the derivative $y' = dy/dx$:
$$ y' = \sqrt{\frac{2a - y}{y}} \implies dx = \sqrt{\frac{y}{2a - y}} \, dy $$

The total trajectory $x(y)$ is given by the integral:
$$ x = \int \sqrt{\frac{y}{2a - y}} \, dy $$

#### Step-by-Step Evaluation of Taylor's Cycloid Substitution
Taylor introduces the parameterized substitution:
$$ y = a(1 - \cos\theta) $$

1. **Differential of the Substitution:**  
   Differentiating $y$ with respect to $\theta$:
   $$ dy = a\sin\theta \, d\theta = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta $$

2. **Simplifying the Radicand:**  
   Substitute $y = a(1 - \cos\theta)$ into the numerator and denominator:
   - Numerator: $y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right)$
   - Denominator: $2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right)$

   Taking the ratio inside the square root:
   $$ \frac{y}{2a - y} = \frac{2a\sin^2(\theta/2)}{2a\cos^2(\theta/2)} = \tan^2\left(\frac{\theta}{2}\right) $$
   Assuming the motion stays within the first arch ($\theta \in [0, 2\pi]$ where $\theta/2 \in [0, \pi]$ and $\sin(\theta/2) \ge 0$):
   $$ \sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin(\theta/2)}{\cos(\theta/2)} $$

3. **Combining and Integrating:**  
   Multiplying the simplified radical by $dy$:
   $$ dx = \left(\frac{\sin(\theta/2)}{\cos(\theta/2)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta = a(1 - \cos\theta) \, d\theta $$
   Integrating directly with initial condition $x(0) = 0$ gives:
   $$ x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta) $$
   These are the parametric equations of a **cycloid**.

#### Mathematical & Physical Rationale for the First Arch ($\theta \in [0, 2\pi]$)
1. **Mathematical Reason (Principal Square Root):**  
   The square root identity is $\sqrt{u^2} = |u|$. Thus:
   $$ \sqrt{\tan^2(\theta/2)} = |\tan(\theta/2)| = \frac{|\sin(\theta/2)|}{|\cos(\theta/2)|} $$
   Within the first arch ($\theta \in [0, 2\pi]$), the half-angle satisfies $\frac{\theta}{2} \in [0, \pi]$, where the sine function is unconditionally non-negative:
   $$ \sin\left(\frac{\theta}{2}\right) \ge 0 \implies \left|\sin\left(\frac{\theta}{2}\right)\right| = \sin\left(\frac{\theta}{2}\right) $$
   This eliminates piece-wise absolute value signs without ambiguity. Along the descending branch ($\theta < \pi$), $\cos(\theta/2) > 0$ and $dy > 0$. Past the trough ($\theta > \pi$), $\cos(\theta/2) < 0$ while the particle ascends ($dy < 0$), maintaining consistent directional progress $dx \ge 0$.

2. **Physical Reason (Energy Bounds & Uniqueness):**  
   - **Energy Ceiling:** By conservation of energy, $v = \sqrt{2gy}$. At $y = 0$, speed vanishes ($v = 0$). The bead cannot ascend into $y < 0$, ensuring the trajectory cannot continue past the cusp at $\theta = 2\pi$.
   - **Path Uniqueness:** By scaling the radius $a$ and endpoint angle $\theta_2 \in (0, 2\pi]$, a unique single cycloid arch connects the origin $(0, 0)$ to any target point $(x_2, y_2)$ with $x_2 > 0, y_2 \ge 0$.
   - **No Redundant Loops:** Any path spanning into subsequent arches would entail climbing to a cusp, arresting, and falling through extra dips, adding superfluous travel time and violating $\delta T = 0$.

#### Why That Substitution Works: The Hidden Circle
Taylor calls $y = a(1 - \cos\theta)$ an "unlikely looking substitution," but it is completely systematic.  
Rationalizing the numerator:
$$ \sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}} $$
Completing the square in the denominator:
$$ 2ay - y^2 = a^2 - (y - a)^2 \implies \int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy $$

**Geometric Origin:**  
The expression $\sqrt{a^2 - (y - a)^2}$ describes a semicircle $(y - a)^2 + w^2 = a^2$ of radius $a$ centered at $(0, a)$.

**Dual Circle Parameterizations:**  
Any form $\sqrt{a^2 - u^2}$ permits two standard circular substitutions:
1. **Sine substitution ($u = a\sin\phi$):** Setting $y - a = a\sin\phi \implies y = a(1 + \sin\phi)$. At the release point $y = 0$, $\sin\phi = -1 \implies \phi = -\pi/2$, imposing an unwanted phase shift.
2. **Inverted cosine substitution ($u = -a\cos\theta$):** Setting $y - a = -a\cos\theta \implies y = a(1 - \cos\theta)$. At release ($y = 0$), $\cos(0) = 1 \implies \theta = 0$, matching initial rest conditions at the origin with zero phase offset!

#### The Algebraic Alternative: Direct Root Substitution
Rather than guessing a trigonometric form, set the entire linear radical equal to an algebraic variable $u$:
$$ u = \sqrt{\frac{y}{2a - y}} \implies y = \frac{2a u^2}{1 + u^2}, \quad dy = \frac{4a u}{(1 + u^2)^2} \, du $$
The integral becomes:
$$ x = \int u \, dy = 4a \int \frac{u^2}{(1 + u^2)^2} \, du $$

This can be evaluated via two direct methods:

##### Method A: Integration by Parts (Pure Algebraic Route)
Decomposing as $u \cdot \frac{u}{(1 + u^2)^2}$ with $f = u$ and $dg = \frac{u}{(1 + u^2)^2}du \implies g = -\frac{1}{2(1 + u^2)}$:
$$ \int \frac{u^2}{(1 + u^2)^2} \, du = -\frac{u}{2(1 + u^2)} + \frac{1}{2}\int \frac{du}{1 + u^2} = -\frac{u}{2(1 + u^2)} + \frac{1}{2}\arctan(u) $$
Multiplying by $4a$ and enforcing $x(0) = 0$:
$$ x(u) = 2a\arctan(u) - \frac{2a u}{1 + u^2} $$
Setting $u = \tan(\theta/2)$, we find $\arctan(u) = \theta/2$ and $\frac{2u}{1 + u^2} = \sin\theta$, which directly recovers:
$$ x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta) $$

##### Method B: Trigonometric Substitution
Substituting $u = \tan\phi$ with $du = \sec^2\phi \, d\phi$:
$$ 4a \int \frac{\tan^2\phi}{\sec^4\phi}\sec^2\phi \, d\phi = 4a \int \sin^2\phi \, d\phi = 2a(\phi - \sin\phi\cos\phi) $$
Setting $\theta = 2\phi$ immediately produces $x = a(\theta - \sin\theta)$.

#### What $\theta$ Represents Physically
The parameter $\theta$ is the cumulative rotation angle (in radians) of a wheel of radius $a$ rolling without slipping along the underside of the horizontal axis ($y = 0$):

```text
          x=0                         x = a*theta                      x = 2*pi*a
   y=0 ----*-------------------------------O-------------------------------*----> x
           |                              / \                              |
           |                             /   \                             |
           |                            /  a  \                            |
           |                           O-------* P(x,y)                    |
           |                            \ theta/                           |
           |                             \    /                            |
           |                              \  /                             |
           |                               \/                              |
           |                                                               |
           |                               . (Trough: theta = pi, y = 2a)  |
           v y
```

- **Wheel Center Translation:** $(x_c, y_c) = (a\theta, a)$
- **Rim Marker Relative Displacement:** $(\Delta x, \Delta y) = (-a\sin\theta, -a\cos\theta)$
- **Absolute Coordinates:**
  $$ x(\theta) = x_c + \Delta x = a(\theta - \sin\theta), \quad y(\theta) = y_c + \Delta y = a(1 - \cos\theta) $$
- **Local Launch / Slope Angle:**
  $$ \frac{dy}{dx} = \frac{a\sin\theta}{a(1 - \cos\theta)} = \cot\left(\frac{\theta}{2}\right) \implies \psi = \frac{\pi - \theta}{2} $$
  - At release ($\theta \to 0$): $\psi = \pi/2$ (instantaneous vertical drop).
  - At the trough ($\theta = \pi$): $\psi = 0$ (instantaneous horizontal flight).
  - At the terminal cusp ($\theta = 2\pi$): $\psi = -\pi/2$ (instantaneous vertical rise).

#### Essential Mathematical Properties of Cycloids
- **Parametric Equations:** $x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta)$
- **Differential Arc Length:**
  $$ ds = \sqrt{\dot{x}^2 + \dot{y}^2} \, d\theta = 2a\sin\left(\frac{\theta}{2}\right) d\theta $$
- **Cumulative Arc Length from Origin:**
  $$ s(\theta) = \int_0^\theta 2a\sin\left(\frac{\theta'}{2}\right) d\theta' = 4a\left(1 - \cos\left(\frac{\theta}{2}\right)\right) = 8a\sin^2\left(\frac{\theta}{4}\right) $$
  A full single arch ($\theta = 2\pi$) has total perimeter $s_{\text{total}} = 8a$.
- **Radius of Curvature:**
  $$ \rho(\theta) = 4a\sin\left(\frac{\theta}{2}\right) = \sqrt{8a y} $$
- **Self-Evolute Property:** The evolute of a cycloid is an identical cycloid shifted horizontally by $\pi a$ and downward by $2a$.

### Maximum and Minimum vs. Stationary
You have probably noticed that we haven't rigorously checked if the cycloid gives a true *minimum* time, as opposed to a maximum or saddle point. For instance, the geodesic between two points on a globe is a great circle. While the shortest path is a great circle, the *long* way around the globe on the same great circle is also a stationary path, but it is neither a minimum nor a maximum (it's a saddle point).

#### ⚠️ Stationary Action vs. "Least" Action in Physics

A common conceptual question in variational calculus and classical mechanics is: **Does the physical trajectory minimize, maximize, or merely make the action stationary? And why is this distinction almost entirely ignored in classical mechanics?**

#### 1. Why the Distinction is Irrelevant for Classical Mechanics
Hamilton's principle states that the true physical trajectory satisfies:
$$ \delta S = 0 \quad \text{where} \quad S[q] = \int_{t_1}^{t_2} L(q, \dot{q}, t) \, dt $$
The derivation of the Euler-Lagrange equations—and therefore Newton's second law $\mathbf{F} = m\mathbf{a}$—rests **entirely and exclusively on the vanishing of the first variation** ($\delta S = 0$). 
* The dynamical equations of motion are **local in time** differential equations. 
* A particle propagating along a trajectory does not "anticipate" or "calculate" the global second variation $\delta^2 S$ across the whole time interval $[t_1, t_2]$.
* Whether $\delta^2 S > 0$ (local minimum), $\delta^2 S < 0$ (local maximum), or $\delta^2 S$ is indefinite (saddle point) has **zero impact** on whether the path satisfies $\frac{\partial L}{\partial q} - \frac{d}{dt}\frac{\partial L}{\partial \dot{q}} = 0$.

Historically, Maupertuis and Euler dubbed this the *"Principle of Least Action"*, believing nature operates with divine economy. However, calling it "least" action is a **historical misnomer**. In fact, for sufficiently long trajectories, true physical paths are almost never global minima—they are **saddle points**. Hence, modern physics refers to it strictly as the **Principle of Stationary Action**.

*(Note: In static equilibrium, $\delta V = 0$ gives equilibrium, but $\delta^2 V > 0$ is indeed required for stability. But for dynamical trajectories, stationarity is all that mechanics requires.)*

---

#### 2. Where and When Does Min vs. Max vs. Saddle Point Matter?
While ordinary classical trajectories require only $\delta S = 0$, distinguishing the character of the stationary point becomes critical in several advanced domains:

1. **Gravitational Lensing & Fermat's Principle (Geometrical Optics):**
   Light rays follow paths of stationary travel time ($\delta t = 0$). When a massive galaxy or cluster gravitationally lenses a background quasar, the light travel-time surface $t(\boldsymbol{\theta})$ has multiple stationary points:
   * **Local Minima:** Arrive first, produce bright, positive-parity images (Type I).
   * **Saddle Points:** Arrive second, produce inverted, negative-parity images (Type II).
   * **Local Maxima:** Arrive last, located near the dense core of the lens galaxy, and are typically highly demagnified (Type III).
   The famous *Odd Number Theorem* in gravitational lensing relies directly on Morse theory characterizing these critical points!

2. **Quantum Mechanics & Feynman Path Integrals:**
   In Feynman's path integral formulation, the transition amplitude sums over *all* conceivable paths:
   $$ K(x_b, t_b; x_a, t_a) = \int \mathcal{D}[x(t)] \, e^{i S[x] / \hbar} $$
   In the classical limit $\hbar \to 0$, paths with $\delta S \ne 0$ experience destructive phase interference and cancel out, leaving the stationary path $\delta S = 0$. However, the **quantum fluctuations** around the classical path are governed by the second variation $\delta^2 S$:
   * The eigenvalues of the second-variation operator determine the **Van Vleck determinant** and phase shifts called the **Maslov index**. Every time a classical path passes through a focal/conjugate point, the quantum wavefunction acquires an extra phase shift of $e^{-i\pi/2}$.

3. **Quantum Tunneling & Instanton Calculations:**
   In Euclidean field theory (wick-rotated imaginary time $\tau = it$), the Euclidean action $S_E$ governs false-vacuum decay and barrier penetration. A true physical "bounce" (instanton) that mediates tunneling must have **precisely one negative eigenvalue** in its second variation operator $\delta^2 S_E$. That solitary negative mode is the mathematical signature of metastability!

4. **Spacetime Geodesics in General Relativity:**
   For timelike worldlines of freely falling test particles between two events, the action is proportional to the proper time: $S = -mc \int d\tau$. Here, free fall actually **maximizes** proper time locally (the twin paradox: the unaccelerated twin ages the most).

#### 3. Why Is This Question in General Hard to Answer?
In single-variable calculus, determining whether $f'(x_0) = 0$ is a min or max requires merely computing the single scalar second derivative $f''(x_0)$. 

In the calculus of variations, however, the action $S[y]$ is a functional defined on an **infinite-dimensional function space** (the space of all differentiable paths $\eta(x)$ satisfying $\eta(x_1) = \eta(x_2) = 0$). The second variation is a differential operator:
$$ \delta^2 S = \frac{1}{2} \int_{x_1}^{x_2} \left[ P(x) (\eta')^2 + Q(x) \eta^2 \right] dx $$
where $P(x) = \frac{\partial^2 f}{\partial y'^2}$ and $Q(x) = \frac{\partial^2 f}{\partial y^2} - \frac{d}{dx}\left(\frac{\partial^2 f}{\partial y \partial y'}\right)$.

Determining whether $\delta^2 S > 0$ for **all possible variations** $\eta(x)$ is difficult because:

1. **Legendre's Condition is Only Necessary, Not Sufficient:**
   The condition $P(x) = \frac{\partial^2 f}{\partial y'^2} > 0$ ensures that very rapid, high-frequency wiggles (where $\eta'$ dominates $\eta$) increase the action. But it tells you nothing about smooth, long-wavelength variations!
2. **Jacobi's Condition & Conjugate Points:**
   To verify a true local minimum, one must solve the **Jacobi accessory differential equation**:
   $$ \frac{d}{dx}\left( P(x) \frac{du}{dx} \right) - Q(x) u = 0 $$
   If there exists an intermediate point $x^* \in (x_1, x_2)$—called a **conjugate point** (or focal point)—where a non-trivial solution vanishes ($u(x_1) = 0$ and $u(x^*) = 0$), then the path **immediately ceases to be a minimum**! Beyond the conjugate point, one can construct an envelope of variations for which $\delta^2 S < 0$, turning the stationary path into a **saddle point**.

##### Concrete Example: The Simple Harmonic Oscillator
Consider a 1D harmonic oscillator with Lagrangian $L = \frac{1}{2}m\dot{x}^2 - \frac{1}{2}m\omega^2 x^2$, starting at $x(0) = 0$ and arriving at $x(T) = 0$:
* The stationary path is $x(t) = 0$ for all $t$.
* The Legendre condition is $P = \frac{\partial^2 L}{\partial \dot{x}^2} = m > 0$ (trivially satisfied).
* Now evaluate the second variation for a variation $\eta(t) = \sin(\pi t / T)$:
  $$ \delta^2 S = \frac{1}{2} \int_0^T \left[ m \left(\frac{\pi}{T}\right)^2 \cos^2\left(\frac{\pi t}{T}\right) - m\omega^2 \sin^2\left(\frac{\pi t}{T}\right) \right] dt = \frac{m T}{4} \left[ \left(\frac{\pi}{T}\right)^2 - \omega^2 \right] $$
* **Case 1 ($T < \pi/\omega$, less than half a period):** $\left(\frac{\pi}{T}\right)^2 > \omega^2 \implies \delta^2 S > 0$. The path is a **strict local minimum**.
* **Case 2 ($T = \pi/\omega$, exactly half a period):** $t^* = \pi/\omega$ is a **conjugate point**. At this point, infinitely many physical trajectories (all amplitudes $A \sin(\omega t)$) have the exact same action!
* **Case 3 ($T > \pi/\omega$, more than half a period):** $\left(\frac{\pi}{T}\right)^2 < \omega^2 \implies \delta^2 S < 0$! The action is a **saddle point**.

Yet throughout all three cases, the harmonic oscillator obeys the exact same physical laws of motion ($\ddot{x} + \omega^2 x = 0$) without any issue.

## 6.4 More Than Two Variables

If the functional depends on multiple functions $y_1(x), y_2(x), \dots, y_n(x)$,
$$ S = \int_{x_1}^{x_2} f(y_1, \dots, y_n, y_1', \dots, y_n', x) \, dx $$
we can vary each function independently. This leads to a system of $n$ independent Euler-Lagrange equations:
$$ \frac{\partial f}{\partial y_i} - \frac{d}{dx} \frac{\partial f}{\partial y_i'} = 0 \quad \text{for } i = 1, 2, \dots, n $$

This extension is crucial for Lagrangian mechanics in 3D space, where we have coordinates $x(t), y(t), z(t)$, and time $t$ plays the role of the independent variable.

## Summary

The calculus of variations allows us to find stationary paths for functionals. The fundamental tool is the Euler-Lagrange equation, which converts a global variational problem into a local differential equation. This mathematical foundation is what allows us to formulate Lagrangian mechanics based on Hamilton's Principle of stationary action.
