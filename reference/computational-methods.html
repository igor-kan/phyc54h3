Introduction

In classical mechanics, analytic solutions are often impossible for systems that exhibit nonlinear dynamics, chaos, or lack conservation laws (e.g., the double pendulum, the 3-body problem, or driven damped oscillators). For these, we rely on numerical integration of Ordinary Differential Equations (ODEs).

Any \(n\)-th order ODE can be reduced to a system of \(n\) first-order ODEs. For Newton’s second law \(\ddot{\mathbf{x}} = \mathbf{F}(\mathbf{x}, \mathbf{v}, t)/m\), we define the state vector \(\mathbf{Y} = [\mathbf{x}, \mathbf{v}]^T\): \[ \frac{d\mathbf{Y}}{dt} = \begin{bmatrix} \mathbf{v} \\ \mathbf{a} \end{bmatrix} = \begin{bmatrix} \mathbf{v} \\ \mathbf{F}/m \end{bmatrix} \]

1. Forward Euler Method (1st Order)

The simplest, but least accurate method. It uses the derivative at the beginning of the timestep \(\Delta t\) to step forward. \[ \mathbf{x}_{n+1} = \mathbf{x}_n + \mathbf{v}_n \Delta t \] \[ \mathbf{v}_{n+1} = \mathbf{v}_n + \mathbf{a}_n \Delta t \]

Drawbacks: Euler’s method accumulates error at \(\mathcal{O}(\Delta t)\). Crucially for mechanics, it does not conserve energy for oscillatory systems, often causing orbits to spiral outward artificially.

2. Symplectic Integrators (Verlet / Leapfrog)

For Hamiltonian systems (where energy is conserved), standard Runge-Kutta methods can still cause long-term energy drift. Symplectic integrators preserve the phase-space volume over time, meaning energy oscillates slightly around the true value but never diverges.

The Velocity Verlet Method

Used extensively in molecular dynamics and astrophysics: 1. Update position by a half-step and full-step acceleration: \[ \mathbf{x}_{n+1} = \mathbf{x}_n + \mathbf{v}_n \Delta t + \frac{1}{2}\mathbf{a}_n \Delta t^2 \] 2. Calculate new forces/accelerations based on new position: \[ \mathbf{a}_{n+1} = \frac{1}{m} \mathbf{F}(\mathbf{x}_{n+1}) \] 3. Update velocity using the average of old and new accelerations: \[ \mathbf{v}_{n+1} = \mathbf{v}_n + \frac{1}{2}(\mathbf{a}_n + \mathbf{a}_{n+1}) \Delta t \]

Code 
import numpy as np

def velocity_verlet(x0, v0, force_func, m, dt, steps):
    x = np.zeros(steps)
    v = np.zeros(steps)
    x[0], v[0] = x0, v0
    
    a = force_func(x0) / m
    for i in range(steps - 1):
        x[i+1] = x[i] + v[i]*dt + 0.5*a*dt**2
        a_next = force_func(x[i+1]) / m
        v[i+1] = v[i] + 0.5*(a + a_next)*dt
        a = a_next
        
    return x, v

3. 4th-Order Runge-Kutta (RK4)

The “workhorse” of numerical ODEs. It evaluates the derivatives at four points within the timestep interval and takes a weighted average, yielding error of \(\mathcal{O}(\Delta t^4)\).

For \(\frac{d\mathbf{Y}}{dt} = f(t, \mathbf{Y})\): \[ \mathbf{k}_1 = f(t_n, \mathbf{Y}_n) \] \[ \mathbf{k}_2 = f(t_n + \frac{\Delta t}{2}, \mathbf{Y}_n + \mathbf{k}_1 \frac{\Delta t}{2}) \] \[ \mathbf{k}_3 = f(t_n + \frac{\Delta t}{2}, \mathbf{Y}_n + \mathbf{k}_2 \frac{\Delta t}{2}) \] \[ \mathbf{k}_4 = f(t_n + \Delta t, \mathbf{Y}_n + \mathbf{k}_3 \Delta t) \] \[ \mathbf{Y}_{n+1} = \mathbf{Y}_n + \frac{\Delta t}{6}(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4) \]

Code 
def rk4_step(Y, t, dt, derivs):
    k1 = derivs(Y, t)
    k2 = derivs(Y + 0.5*dt*k1, t + 0.5*dt)
    k3 = derivs(Y + 0.5*dt*k2, t + 0.5*dt)
    k4 = derivs(Y + dt*k3, t + dt)
    return Y + (dt/6.0) * (k1 + 2*k2 + 2*k3 + k4)

SciPy Integration (solve_ivp)

In Python, the scipy.integrate.solve_ivp function provides a highly optimized, adaptive-timestep interface for these methods (defaulting to the RK45 method).

Code 
from scipy.integrate import solve_ivp

# Define the state derivative for a simple harmonic oscillator
# Y = [x, v] -> dY/dt = [v, -k/m x]
def sho_derivs(t, Y, k=1.0, m=1.0):
    x, v = Y
    return [v, -(k/m)*x]

# Solve from t=0 to t=10 with initial conditions x=1, v=0
sol = solve_ivp(sho_derivs, [0, 10], [1.0, 0.0], t_eval=np.linspace(0, 10, 100))

# sol.t contains the time array
# sol.y[0] contains x(t)
# sol.y[1] contains v(t)

# Introduction

In classical mechanics, analytic solutions are often impossible for systems that exhibit nonlinear dynamics, chaos, or lack conservation laws (e.g., the double pendulum, the 3-body problem, or driven damped oscillators). For these, we rely on **numerical integration** of Ordinary Differential Equations (ODEs).

Any $n$-th order ODE can be reduced to a system of $n$ first-order ODEs. For Newton's second law $\ddot{\mathbf{x}} = \mathbf{F}(\mathbf{x}, \mathbf{v}, t)/m$, we define the state vector $\mathbf{Y} = [\mathbf{x}, \mathbf{v}]^T$:
$$ \frac{d\mathbf{Y}}{dt} = \begin{bmatrix} \mathbf{v} \\ \mathbf{a} \end{bmatrix} = \begin{bmatrix} \mathbf{v} \\ \mathbf{F}/m \end{bmatrix} $$

---

# 1. Forward Euler Method (1st Order)

The simplest, but least accurate method. It uses the derivative at the beginning of the timestep $\Delta t$ to step forward.
$$ \mathbf{x}_{n+1} = \mathbf{x}_n + \mathbf{v}_n \Delta t $$
$$ \mathbf{v}_{n+1} = \mathbf{v}_n + \mathbf{a}_n \Delta t $$

**Drawbacks:**
Euler's method accumulates error at $\mathcal{O}(\Delta t)$. Crucially for mechanics, **it does not conserve energy** for oscillatory systems, often causing orbits to spiral outward artificially.

---

# 2. Symplectic Integrators (Verlet / Leapfrog)

For Hamiltonian systems (where energy is conserved), standard Runge-Kutta methods can still cause long-term energy drift. **Symplectic integrators** preserve the phase-space volume over time, meaning energy oscillates slightly around the true value but never diverges.

## The Velocity Verlet Method
Used extensively in molecular dynamics and astrophysics:
1. Update position by a half-step and full-step acceleration:
   $$ \mathbf{x}_{n+1} = \mathbf{x}_n + \mathbf{v}_n \Delta t + \frac{1}{2}\mathbf{a}_n \Delta t^2 $$
2. Calculate new forces/accelerations based on new position:
   $$ \mathbf{a}_{n+1} = \frac{1}{m} \mathbf{F}(\mathbf{x}_{n+1}) $$
3. Update velocity using the average of old and new accelerations:
   $$ \mathbf{v}_{n+1} = \mathbf{v}_n + \frac{1}{2}(\mathbf{a}_n + \mathbf{a}_{n+1}) \Delta t $$

```{python}
import numpy as np

def velocity_verlet(x0, v0, force_func, m, dt, steps):
    x = np.zeros(steps)
    v = np.zeros(steps)
    x[0], v[0] = x0, v0
    
    a = force_func(x0) / m
    for i in range(steps - 1):
        x[i+1] = x[i] + v[i]*dt + 0.5*a*dt**2
        a_next = force_func(x[i+1]) / m
        v[i+1] = v[i] + 0.5*(a + a_next)*dt
        a = a_next
        
    return x, v
```

---

# 3. 4th-Order Runge-Kutta (RK4)

The "workhorse" of numerical ODEs. It evaluates the derivatives at four points within the timestep interval and takes a weighted average, yielding error of $\mathcal{O}(\Delta t^4)$.

For $\frac{d\mathbf{Y}}{dt} = f(t, \mathbf{Y})$:
$$ \mathbf{k}_1 = f(t_n, \mathbf{Y}_n) $$
$$ \mathbf{k}_2 = f(t_n + \frac{\Delta t}{2}, \mathbf{Y}_n + \mathbf{k}_1 \frac{\Delta t}{2}) $$
$$ \mathbf{k}_3 = f(t_n + \frac{\Delta t}{2}, \mathbf{Y}_n + \mathbf{k}_2 \frac{\Delta t}{2}) $$
$$ \mathbf{k}_4 = f(t_n + \Delta t, \mathbf{Y}_n + \mathbf{k}_3 \Delta t) $$
$$ \mathbf{Y}_{n+1} = \mathbf{Y}_n + \frac{\Delta t}{6}(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4) $$

```{python}
def rk4_step(Y, t, dt, derivs):
    k1 = derivs(Y, t)
    k2 = derivs(Y + 0.5*dt*k1, t + 0.5*dt)
    k3 = derivs(Y + 0.5*dt*k2, t + 0.5*dt)
    k4 = derivs(Y + dt*k3, t + dt)
    return Y + (dt/6.0) * (k1 + 2*k2 + 2*k3 + k4)
```
