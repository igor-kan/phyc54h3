Introduction to the Calculus of Variations

In classical mechanics, we often encounter problems where we need to find a path or a function that minimizes (or maximizes) a certain quantity. This is the domain of the Calculus of Variations. While ordinary calculus deals with finding points that extremize a function \(y = f(x)\), the calculus of variations deals with finding functions \(y(x)\) that extremize a functional (a function of a function), often expressed as an integral:

\[ S = \int_{x_1}^{x_2} f(y, y', x) \, dx \]

Two main classes of problems require this approach: 1. Symmetries make non-Cartesian coordinates (spherical, cylindrical) advantageous. 2. Constraints make it best to choose generalized coordinates (e.g., a particle on a sphere).

To transition to these generalized coordinates, Lagrangian mechanics provides a powerful framework built entirely on the calculus of variations and Hamilton’s Principle of Least Action.

6.1 Two Examples

Example 1: The Shortest Path Between Two Points

What is the shortest path between two points \((x_1, y_1)\) and \((x_2, y_2)\) in a plane? Let the path be given by a function \(y = y(x)\). An infinitesimal element of length along the path is \(ds = \sqrt{dx^2 + dy^2} = \sqrt{1 + (y')^2} \, dx\), where \(y' = dy/dx\).

The total length of the path is the integral: \[ L = \int_{x_1}^{x_2} \sqrt{1 + [y'(x)]^2} \, dx \]

The goal is to find the function \(y(x)\) that minimizes \(L\).

(See Problem 6.1)

Example 2: The Brachistochrone Problem

First posed by Johann Bernoulli in 1696. Given two points 1 and 2, with 1 higher than 2, what is the shape of a frictionless wire connecting them such that a bead released from rest at 1 slides to 2 in the minimum possible time?

Let point 1 be the origin \((0,0)\). We take the \(y\)-axis pointing downward. The speed of the bead is \(v = ds/dt\). By conservation of energy, \(E = T + U\). If released from rest at \((0,0)\), \(E = 0\). \[ \frac{1}{2}mv^2 - mgy = 0 \implies v = \sqrt{2gy} \]

The time to travel an infinitesimal distance \(ds\) is \(dt = ds/v\). The total time is: \[ t = \int_{1}^{2} \frac{ds}{v} = \int_{x_1}^{x_2} \frac{\sqrt{1 + (y')^2}}{\sqrt{2gy}} \, dx \]

We need to find the function \(y(x)\) that minimizes this time integral \(t\).

(See Problem 6.2)

6.2 The Euler-Lagrange Equation

Both examples above involve an integral of the form: \[ S[y] = \int_{x_1}^{x_2} f(y, y', x) \, dx \] where \(S\) is a functional. We want to find the path \(y(x)\) that makes \(S\) stationary (a minimum, maximum, or saddle point).

Derivation

Let the actual path that extremizes the integral be \(y(x)\). Consider a “wrong” path \(Y(x)\) that is close to \(y(x)\). We can parameterize this wrong path as: \[ Y(x) = y(x) + \alpha \eta(x) \] where \(\alpha\) is a small parameter, and \(\eta(x)\) is an arbitrary differentiable function representing the variation. Since all paths must start at \(x_1\) and end at \(x_2\), the variation must vanish at the endpoints: \[ \eta(x_1) = \eta(x_2) = 0 \]

The integral evaluated along the varied path is a function of \(\alpha\): \[ S(\alpha) = \int_{x_1}^{x_2} f(Y, Y', x) \, dx = \int_{x_1}^{x_2} f(y + \alpha \eta, y' + \alpha \eta', x) \, dx \]

For the integral to be stationary at the correct path \(y(x)\), the derivative of \(S\) with respect to \(\alpha\) must be zero when \(\alpha = 0\): \[ \left. \frac{dS}{d\alpha} \right|_{\alpha=0} = 0 \]

Using the chain rule to differentiate inside the integral: \[ \frac{dS}{d\alpha} = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \frac{\partial Y}{\partial \alpha} + \frac{\partial f}{\partial Y'} \frac{\partial Y'}{\partial \alpha} \right) dx = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \eta + \frac{\partial f}{\partial Y'} \eta' \right) dx \]

Set \(\alpha = 0\), so \(Y \to y\) and \(Y' \to y'\): \[ \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial y} \eta(x) + \frac{\partial f}{\partial y'} \eta'(x) \right) dx = 0 \]

We integrate the second term by parts: \[ \int_{x_1}^{x_2} \frac{\partial f}{\partial y'} \eta'(x) \, dx = \left[ \frac{\partial f}{\partial y'} \eta(x) \right]_{x_1}^{x_2} - \int_{x_1}^{x_2} \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \eta(x) \, dx \]

Since \(\eta(x_1) = \eta(x_2) = 0\), the boundary term vanishes. The condition becomes: \[ \int_{x_1}^{x_2} \left[ \frac{\partial f}{\partial y} - \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \right] \eta(x) \, dx = 0 \]

For this to hold for any arbitrary variation \(\eta(x)\), the term in the brackets must be identically zero. This yields the Euler-Lagrange Equation:

\[ \frac{\partial f}{\partial y} - \frac{d}{dx} \frac{\partial f}{\partial y'} = 0 \]

(See Problem 6.4)

6.3 Applications of the Euler-Lagrange Equation

1. Shortest Path Revisited

For the shortest path, \(f(y, y', x) = \sqrt{1 + y'^2}\). Since \(\partial f / \partial y = 0\), the E-L equation reduces to: \[ \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) = 0 \implies \frac{\partial f}{\partial y'} = C \] \[ \frac{y'}{\sqrt{1 + y'^2}} = C \implies y'^2 = C^2(1 + y'^2) \implies y'^2 = \frac{C^2}{1-C^2} = m^2 \] Thus, \(y' = m\), meaning \(y = mx + b\). The shortest path is a straight line.

2. The Brachistochrone Solution

For the Brachistochrone, \(f = \sqrt{\frac{1+y'^2}{y}}\) (ignoring constants). Notice that \(f\) does not depend explicitly on \(x\). When \(\partial f / \partial x = 0\), we can use the Beltrami Identity (a first integral of the E-L equation): \[ f - y' \frac{\partial f}{\partial y'} = C \]

Substituting \(f\): \[ \sqrt{\frac{1+y'^2}{y}} - y' \frac{y'}{\sqrt{y(1+y'^2)}} = C \] \[ \frac{1+y'^2 - y'^2}{\sqrt{y(1+y'^2)}} = C \implies \frac{1}{\sqrt{y(1+y'^2)}} = C \implies y(1+y'^2) = \frac{1}{C^2} = 2a \]

Solving for \(y'\): \[ y' = \frac{dy}{dx} = \sqrt{\frac{2a-y}{y}} \implies dx = \sqrt{\frac{y}{2a-y}} dy \]

The integral to evaluate is therefore: \[ x = \int \sqrt{\frac{y}{2a - y}} \, dy \]

Step-by-Step Evaluation of Taylor’s Cycloid Substitution

Taylor introduces the substitution: \[ y = a(1 - \cos\theta) \]

  1. Differential of the Substitution:
    Differentiating \(y\) with respect to \(\theta\): \[ dy = \frac{d}{d\theta}\big[a(1 - \cos\theta)\big] d\theta = a\sin\theta \, d\theta \] Using the double-angle identity \(\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)\): \[ dy = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta \]

  2. Simplifying the Radicand:
    Substitute \(y = a(1 - \cos\theta)\) into the numerator and denominator under the radical:

    • Numerator: \[ y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right) \]
    • Denominator: \[ 2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right) \] Taking the ratio inside the square root: \[ \frac{y}{2a - y} = \frac{2a\sin^2\left(\frac{\theta}{2}\right)}{2a\cos^2\left(\frac{\theta}{2}\right)} = \tan^2\left(\frac{\theta}{2}\right) \]

    Why We Assume the First Arch (\(\theta \in [0, 2\pi]\) and \(\sin(\theta/2) \ge 0\)):
    The principal square root of any real square evaluates to its absolute value: \(\sqrt{\tan^2(\theta/2)} = |\tan(\theta/2)| = \frac{|\sin(\theta/2)|}{|\cos(\theta/2)|}\).

    • In any single Brachistochrone descent starting from rest at the origin \((0,0)\), energy conservation dictates \(v = \sqrt{2gy}\). The bead cannot ascend higher than its release height \(y = 0\), meaning the curve terminates before or at the completion of a single revolution of the generating wheel (\(\theta \le 2\pi\)). Hence the relevant motion is strictly confined within the first arch: \(\theta \in [0, 2\pi]\), giving \(\frac{\theta}{2} \in [0, \pi]\).
    • Across the entire half-angle domain \([0, \pi]\), the sine function is unconditionally non-negative (\(\sin(\theta/2) \ge 0\)). Therefore, the absolute value on the sine can be dropped without piecewise branching: \[ \left|\sin\left(\frac{\theta}{2}\right)\right| = \sin\left(\frac{\theta}{2}\right) \]
    • For the denominator, \(\cos(\theta/2) > 0\) along the entire descending branch \(\theta \in [0, \pi)\), where \(y\) is increasing from \(0\) to \(2a\). When the particle crosses the trough at \(\theta = \pi\), \(\cos(\theta/2)\) changes sign as \(y\) begins decreasing, while \(dx/d\theta = a(1 - \cos\theta) \ge 0\) remains positive throughout. Thus, setting: \[ \sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)} \] correctly captures the trajectory without extraneous signs.

  3. Combining and Integrating:
    Multiply the simplified radical by \(dy\): \[ \sqrt{\frac{y}{2a - y}} \, dy = \left(\frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta \] Recall the half-angle identity \(2\sin^2\left(\frac{\theta}{2}\right) = 1 - \cos\theta\): \[ x = \int a(1 - \cos\theta) \, d\theta = a(\theta - \sin\theta) + C \] Applying the initial condition \(x(0) = 0\) gives \(C = 0\), recovering the cycloid parametric equations: \[ x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta) \]

Why That Substitution Works: The Hidden Circle

Taylor calls this an “unlikely looking substitution,” but it is completely systematic.
Rationalize the numerator of the integrand: \[ \sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}} \] Complete the square in the denominator: \[ 2ay - y^2 = -(y^2 - 2ay + a^2) + a^2 = a^2 - (y - a)^2 \] Now the integral becomes: \[ \int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy \]

Why This Is a Circle:
In the \((w, y)\) plane, the equation \(w = \sqrt{a^2 - (y - a)^2}\) describes the boundary of a circle of radius \(a\) centered at \((0, a)\): \[ w^2 + (y - a)^2 = a^2 \]

Why Two Different Types of \(u\) Can Be Substituted:
Any expression involving \(\sqrt{a^2 - u^2}\) naturally invites a circular parameterization, but we have two standard choices depending on the angle reference axis: 1. The Sine Substitution (\(u = a\sin\phi\)):
If we set \(y - a = a\sin\phi\), then \(y = a(1 + \sin\phi)\). Here the angle \(\phi\) is measured relative to the horizontal diameter of the circle. At the release point (\(y = 0\)), this requires \(\sin\phi = -1 \implies \phi = -\pi/2\). While mathematically valid, it introduces an awkward phase shift of \(-\pi/2\) into the equations of motion. 2. The Inverted Cosine Substitution (\(u = -a\cos\theta\)):
If we instead set \(y - a = -a\cos\theta\), then: \[ y = a(1 - \cos\theta) \] Here the angle \(\theta\) is measured from the top apex of the circle. At \(\theta = 0\), \(\cos(0) = 1\), which gives \(y = a(1 - 1) = 0\) automatically! Thus, the negative cosine choice is physically tailored to align \(\theta = 0\) directly with the initial release point at the origin without requiring arbitrary phase angles.

The Algebraic Alternative: Direct Root Substitution (With Both Integration by Parts and Trig Methods)

You do not need to guess a trigonometric substitution. When faced with any rational function of a single linear radical \(\sqrt{\frac{a y + b}{c y + d}}\), set the entire radical equal to a new algebraic variable \(u\): \[ u = \sqrt{\frac{y}{2a - y}} \] Inverting for \(y\): \[ u^2 = \frac{y}{2a - y} \implies u^2(2a - y) = y \implies 2a u^2 = y(1 + u^2) \implies y = \frac{2a u^2}{1 + u^2} \] Compute \(dy\): \[ dy = 2a \frac{d}{du}\left[1 - \frac{1}{1 + u^2}\right] du = \frac{4a u}{(1 + u^2)^2} \, du \] Substitute into the integral \(x = \int u \, dy\): \[ x = \int u \cdot \frac{4a u}{(1 + u^2)^2} \, du = 4a \int \frac{u^2}{(1 + u^2)^2} \, du \]

We can solve this integral via two independent pathways:

Method A: Integration by Parts (Pure Algebraic Route)

Split the numerator as \(u \cdot \frac{u}{(1+u^2)^2}\): - Let \(f = u \implies df = du\) - Let \(dg = \frac{u}{(1+u^2)^2} \, du \implies g = -\frac{1}{2(1+u^2)}\)

Applying \(\int f \, dg = fg - \int g \, df\): \[ \int \frac{u^2}{(1+u^2)^2} \, du = -\frac{u}{2(1+u^2)} + \frac{1}{2}\int \frac{du}{1+u^2} = -\frac{u}{2(1+u^2)} + \frac{1}{2}\arctan(u) \] Multiplying by the overall factor \(4a\): \[ x(u) = 2a \arctan(u) - \frac{2a u}{1 + u^2} + C \] Since \(u = 0\) at \(y = 0\), the boundary condition \(x(0) = 0\) enforces \(C = 0\).
To interpret this geometrically, let \(u = \tan\left(\frac{\theta}{2}\right)\). Then: - \(\arctan(u) = \frac{\theta}{2}\) - \(\frac{2u}{1+u^2} = \frac{2\tan(\theta/2)}{1+\tan^2(\theta/2)} = \sin\theta\) (the standard double-angle identity)

Substituting these directly into \(x(u)\): \[ x(\theta) = 2a\left(\frac{\theta}{2}\right) - a\sin\theta = a(\theta - \sin\theta) \] And for \(y\): \[ y = \frac{2a u^2}{1+u^2} = 2a\sin^2\left(\frac{\theta}{2}\right) = a(1 - \cos\theta) \] This recovers the cycloid parametric equations without having to guess the substitution upfront!

Method B: Trigonometric Substitution

Setting \(u = \tan\phi\), so \(du = \sec^2\phi \, d\phi\): \[ 4a \int \frac{\tan^2\phi}{(1+\tan^2\phi)^2} \sec^2\phi \, d\phi = 4a \int \frac{\tan^2\phi}{\sec^4\phi}\sec^2\phi \, d\phi = 4a \int \sin^2\phi \, d\phi \] Using \(\sin^2\phi = \frac{1 - \cos 2\phi}{2}\): \[ 4a \int \left(\frac{1 - \cos 2\phi}{2}\right) d\phi = 2a\left(\phi - \frac{1}{2}\sin 2\phi\right) = 2a(\phi - \sin\phi\cos\phi) \] Setting \(\theta = 2\phi\) (so \(\phi = \theta/2\)), this immediately yields \(x(\theta) = a(\theta - \sin\theta)\).

What \(\theta\) Represents Physically

The parameter \(\theta\) is the cumulative rotation angle (in radians) of the rolling circle that generates the curve:

Imagine a circular disk of radius \(a\) rolling without slipping along the underside of the horizontal axis (\(y = 0\), pointing downward): - Center of the wheel: As the wheel rolls through an angle \(\theta\), its contact point has rolled a distance \(a\theta\) along the rail: \[ (x_c, y_c) = (a\theta, a) \] - Point on the perimeter (\(P\)): A marker fixed to the rim starts at the origin \((0, 0)\) when \(\theta = 0\). After rotating clockwise by \(\theta\), the marker’s relative displacement from the wheel’s center is: \[ \Delta x = -a\sin\theta, \quad \Delta y = -a\cos\theta \] - Absolute coordinates: Combining center translation and rim rotation yields: \[ x(\theta) = x_c + \Delta x = a(\theta - \sin\theta) \] \[ y(\theta) = y_c + \Delta y = a(1 - \cos\theta) \]

\(\theta\) also directly determines the local slope and launch angle of the path. Differentiating with respect to \(\theta\): \[ \frac{dy}{dx} = \frac{dy/d\theta}{dx/d\theta} = \frac{a\sin\theta}{a(1 - \cos\theta)} = \frac{2\sin(\theta/2)\cos(\theta/2)}{2\sin^2(\theta/2)} = \cot\left(\frac{\theta}{2}\right) \] If \(\psi\) is the inclination angle of the velocity vector relative to the horizontal (\(\tan\psi = dy/dx\)): \[ \psi = \frac{\pi - \theta}{2} \] - At \(\theta \to 0\) (the start): \(\psi = \pi/2\) (the path drops straight vertically). - At \(\theta = \pi\) (the trough): \(\psi = 0\) (the trajectory is completely horizontal). - At \(\theta = 2\pi\) (the next cusp): \(\psi = -\pi/2\) (the path rises back to vertical).

Why Assume the First Arch (\(\theta \in [0, 2\pi]\)) and \(\sin(\theta/2) \ge 0\)?

  1. The Mathematical Reason: Eliminating Absolute Value Signs
    The principal square root satisfies \(\sqrt{u^2} = |u|\). In simplifying the radical: \[ \sqrt{\frac{y}{2a - y}} = \left| \tan\left(\frac{\theta}{2}\right) \right| = \frac{\left|\sin(\theta/2)\right|}{\left|\cos(\theta/2)\right|} \] If \(\theta \in [0, 2\pi]\), then \(\frac{\theta}{2} \in [0, \pi]\). Since sine is strictly non-negative on \([0, \pi]\): \[ \sin\left(\frac{\theta}{2}\right) \ge 0 \implies \left|\sin\left(\frac{\theta}{2}\right)\right| = \sin\left(\frac{\theta}{2}\right) \] This avoids carrying piece-wise \(\pm\) absolute value signs.

  2. The Physical Reason: Geometry of the Fastest Path

    • Energy Bounds: Conservation of mechanical energy gives \(v = \sqrt{2gy}\). At \(y = 0\), speed is zero (\(v = 0\)). The particle cannot rise above \(y = 0\), so it cannot continue past a cusp into negative \(y\).
    • Uniqueness: A single arch (\(\theta \in [0, 2\pi]\)) starts at \((0, 0)\) and terminates at \((2\pi a, 0)\). By scaling the radius \(a\), a single cycloid arch can pass through any target point \((x_2, y_2)\) in the lower half-plane (\(x_2 > 0, y_2 \ge 0\)).
    • No Redundant Loops: Any path extending past \(\theta = 2\pi\) into a second arch would involve rising up to a cusp, stopping, and dropping into a new dip. That would add unnecessary path length and travel time, violating the time-minimization condition \(\delta T = 0\).

Essential Mathematical Properties of Cycloids

  • Parametric Form: \(x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta)\)
  • Differential Arc Length: \[ ds = \sqrt{\dot{x}^2 + \dot{y}^2}\, d\theta = a\sqrt{(1-\cos\theta)^2 + \sin^2\theta}\, d\theta = 2a\sin\left(\frac{\theta}{2}\right) d\theta \]
  • Total Arc Length from Origin to \(\theta\): \[ s(\theta) = \int_0^\theta 2a\sin\left(\frac{\theta'}{2}\right) d\theta' = 4a\left(1 - \cos\left(\frac{\theta}{2}\right)\right) = 8a\sin^2\left(\frac{\theta}{4}\right) \] The total perimeter of one complete arch (\(\theta = 2\pi\)) is exactly \(s_{\text{total}} = 8a\).
  • Radius of Curvature: \[ \rho(\theta) = \frac{(\dot{x}^2 + \dot{y}^2)^{3/2}}{|\dot{x}\ddot{y} - \dot{y}\ddot{x}|} = 4a\sin\left(\frac{\theta}{2}\right) = \sqrt{8a y} \]
  • Self-Evolute Property: The evolute (locus of centers of curvature) of a cycloid is an identical cycloid, shifted horizontally by \(\pi a\) and vertically downward by \(2a\).

6.4 More Than Two Variables

If the functional depends on multiple functions \(y_1(x), y_2(x), \dots, y_n(x)\), \[ S = \int_{x_1}^{x_2} f(y_1, \dots, y_n, y_1', \dots, y_n', x) \, dx \] we can vary each function independently. This leads to a system of \(n\) independent Euler-Lagrange equations: \[ \frac{\partial f}{\partial y_i} - \frac{d}{dx} \frac{\partial f}{\partial y_i'} = 0 \quad \text{for } i = 1, 2, \dots, n \]

This extension is crucial for Lagrangian mechanics in 3D space, where we have coordinates \(x(t), y(t), z(t)\), and time \(t\) plays the role of the independent variable.

(See Problem 6.22)

Summary

The calculus of variations allows us to find stationary paths for functionals. The fundamental tool is the Euler-Lagrange equation, which converts a global variational problem into a local differential equation. This mathematical foundation is what allows us to formulate Lagrangian mechanics based on Hamilton’s Principle of stationary action.

# Introduction to the Calculus of Variations

In classical mechanics, we often encounter problems where we need to find a path or a function that minimizes (or maximizes) a certain quantity. This is the domain of the **Calculus of Variations**. While ordinary calculus deals with finding points that extremize a function $y = f(x)$, the calculus of variations deals with finding *functions* $y(x)$ that extremize a *functional* (a function of a function), often expressed as an integral:

$$ S = \int_{x_1}^{x_2} f(y, y', x) \, dx $$

Two main classes of problems require this approach:
1. Symmetries make non-Cartesian coordinates (spherical, cylindrical) advantageous.
2. Constraints make it best to choose generalized coordinates (e.g., a particle on a sphere).

To transition to these generalized coordinates, Lagrangian mechanics provides a powerful framework built entirely on the calculus of variations and Hamilton's Principle of Least Action.

## 6.1 Two Examples

### Example 1: The Shortest Path Between Two Points

What is the shortest path between two points $(x_1, y_1)$ and $(x_2, y_2)$ in a plane? Let the path be given by a function $y = y(x)$. An infinitesimal element of length along the path is $ds = \sqrt{dx^2 + dy^2} = \sqrt{1 + (y')^2} \, dx$, where $y' = dy/dx$.

The total length of the path is the integral:
$$ L = \int_{x_1}^{x_2} \sqrt{1 + [y'(x)]^2} \, dx $$

The goal is to find the function $y(x)$ that minimizes $L$.

*(See [Problem 6.1](../solutions/taylor-chapter-6-problems.qmd#problem-61))*

### Example 2: The Brachistochrone Problem

First posed by Johann Bernoulli in 1696. Given two points 1 and 2, with 1 higher than 2, what is the shape of a frictionless wire connecting them such that a bead released from rest at 1 slides to 2 in the minimum possible time?

Let point 1 be the origin $(0,0)$. We take the $y$-axis pointing *downward*.
The speed of the bead is $v = ds/dt$. By conservation of energy, $E = T + U$. If released from rest at $(0,0)$, $E = 0$.
$$ \frac{1}{2}mv^2 - mgy = 0 \implies v = \sqrt{2gy} $$

The time to travel an infinitesimal distance $ds$ is $dt = ds/v$. The total time is:
$$ t = \int_{1}^{2} \frac{ds}{v} = \int_{x_1}^{x_2} \frac{\sqrt{1 + (y')^2}}{\sqrt{2gy}} \, dx $$

We need to find the function $y(x)$ that minimizes this time integral $t$.

*(See [Problem 6.2](../solutions/taylor-chapter-6-problems.qmd#problem-62))*

## 6.2 The Euler-Lagrange Equation

Both examples above involve an integral of the form:
$$ S[y] = \int_{x_1}^{x_2} f(y, y', x) \, dx $$
where $S$ is a functional. We want to find the path $y(x)$ that makes $S$ stationary (a minimum, maximum, or saddle point).

### Derivation

Let the actual path that extremizes the integral be $y(x)$. Consider a "wrong" path $Y(x)$ that is close to $y(x)$. We can parameterize this wrong path as:
$$ Y(x) = y(x) + \alpha \eta(x) $$
where $\alpha$ is a small parameter, and $\eta(x)$ is an arbitrary differentiable function representing the variation. Since all paths must start at $x_1$ and end at $x_2$, the variation must vanish at the endpoints:
$$ \eta(x_1) = \eta(x_2) = 0 $$

The integral evaluated along the varied path is a function of $\alpha$:
$$ S(\alpha) = \int_{x_1}^{x_2} f(Y, Y', x) \, dx = \int_{x_1}^{x_2} f(y + \alpha \eta, y' + \alpha \eta', x) \, dx $$

For the integral to be stationary at the correct path $y(x)$, the derivative of $S$ with respect to $\alpha$ must be zero when $\alpha = 0$:
$$ \left. \frac{dS}{d\alpha} \right|_{\alpha=0} = 0 $$

Using the chain rule to differentiate inside the integral:
$$ \frac{dS}{d\alpha} = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \frac{\partial Y}{\partial \alpha} + \frac{\partial f}{\partial Y'} \frac{\partial Y'}{\partial \alpha} \right) dx = \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial Y} \eta + \frac{\partial f}{\partial Y'} \eta' \right) dx $$

Set $\alpha = 0$, so $Y \to y$ and $Y' \to y'$:
$$ \int_{x_1}^{x_2} \left( \frac{\partial f}{\partial y} \eta(x) + \frac{\partial f}{\partial y'} \eta'(x) \right) dx = 0 $$

We integrate the second term by parts:
$$ \int_{x_1}^{x_2} \frac{\partial f}{\partial y'} \eta'(x) \, dx = \left[ \frac{\partial f}{\partial y'} \eta(x) \right]_{x_1}^{x_2} - \int_{x_1}^{x_2} \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \eta(x) \, dx $$

Since $\eta(x_1) = \eta(x_2) = 0$, the boundary term vanishes. The condition becomes:
$$ \int_{x_1}^{x_2} \left[ \frac{\partial f}{\partial y} - \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) \right] \eta(x) \, dx = 0 $$

For this to hold for *any* arbitrary variation $\eta(x)$, the term in the brackets must be identically zero. This yields the **Euler-Lagrange Equation**:

$$ \frac{\partial f}{\partial y} - \frac{d}{dx} \frac{\partial f}{\partial y'} = 0 $$

*(See [Problem 6.4](../solutions/taylor-chapter-6-problems.qmd#problem-64))*

## 6.3 Applications of the Euler-Lagrange Equation

### 1. Shortest Path Revisited

For the shortest path, $f(y, y', x) = \sqrt{1 + y'^2}$.
Since $\partial f / \partial y = 0$, the E-L equation reduces to:
$$ \frac{d}{dx} \left( \frac{\partial f}{\partial y'} \right) = 0 \implies \frac{\partial f}{\partial y'} = C $$
$$ \frac{y'}{\sqrt{1 + y'^2}} = C \implies y'^2 = C^2(1 + y'^2) \implies y'^2 = \frac{C^2}{1-C^2} = m^2 $$
Thus, $y' = m$, meaning $y = mx + b$. The shortest path is a straight line.

### 2. The Brachistochrone Solution

For the Brachistochrone, $f = \sqrt{\frac{1+y'^2}{y}}$ (ignoring constants).
Notice that $f$ does not depend explicitly on $x$. When $\partial f / \partial x = 0$, we can use the **Beltrami Identity** (a first integral of the E-L equation):
$$ f - y' \frac{\partial f}{\partial y'} = C $$

Substituting $f$:
$$ \sqrt{\frac{1+y'^2}{y}} - y' \frac{y'}{\sqrt{y(1+y'^2)}} = C $$
$$ \frac{1+y'^2 - y'^2}{\sqrt{y(1+y'^2)}} = C \implies \frac{1}{\sqrt{y(1+y'^2)}} = C \implies y(1+y'^2) = \frac{1}{C^2} = 2a $$

Solving for $y'$:
$$ y' = \frac{dy}{dx} = \sqrt{\frac{2a-y}{y}} \implies dx = \sqrt{\frac{y}{2a-y}} dy $$

The integral to evaluate is therefore:
$$ x = \int \sqrt{\frac{y}{2a - y}} \, dy $$

#### Step-by-Step Evaluation of Taylor's Cycloid Substitution

Taylor introduces the substitution:
$$ y = a(1 - \cos\theta) $$

1. **Differential of the Substitution:**  
   Differentiating $y$ with respect to $\theta$:
   $$ dy = \frac{d}{d\theta}\big[a(1 - \cos\theta)\big] d\theta = a\sin\theta \, d\theta $$
   Using the double-angle identity $\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)$:
   $$ dy = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta $$

2. **Simplifying the Radicand:**  
   Substitute $y = a(1 - \cos\theta)$ into the numerator and denominator under the radical:
   - Numerator:
     $$ y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right) $$
   - Denominator:
     $$ 2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right) $$
   Taking the ratio inside the square root:
   $$ \frac{y}{2a - y} = \frac{2a\sin^2\left(\frac{\theta}{2}\right)}{2a\cos^2\left(\frac{\theta}{2}\right)} = \tan^2\left(\frac{\theta}{2}\right) $$
   
   **Why We Assume the First Arch ($\theta \in [0, 2\pi]$ and $\sin(\theta/2) \ge 0$):**  
   The principal square root of any real square evaluates to its absolute value: $\sqrt{\tan^2(\theta/2)} = |\tan(\theta/2)| = \frac{|\sin(\theta/2)|}{|\cos(\theta/2)|}$.  
   - In any single Brachistochrone descent starting from rest at the origin $(0,0)$, energy conservation dictates $v = \sqrt{2gy}$. The bead cannot ascend higher than its release height $y = 0$, meaning the curve terminates before or at the completion of a single revolution of the generating wheel ($\theta \le 2\pi$). Hence the relevant motion is strictly confined within the first arch: $\theta \in [0, 2\pi]$, giving $\frac{\theta}{2} \in [0, \pi]$.
   - Across the entire half-angle domain $[0, \pi]$, the sine function is unconditionally non-negative ($\sin(\theta/2) \ge 0$). Therefore, the absolute value on the sine can be dropped without piecewise branching:
     $$ \left|\sin\left(\frac{\theta}{2}\right)\right| = \sin\left(\frac{\theta}{2}\right) $$
   - For the denominator, $\cos(\theta/2) > 0$ along the entire descending branch $\theta \in [0, \pi)$, where $y$ is increasing from $0$ to $2a$. When the particle crosses the trough at $\theta = \pi$, $\cos(\theta/2)$ changes sign as $y$ begins decreasing, while $dx/d\theta = a(1 - \cos\theta) \ge 0$ remains positive throughout. Thus, setting:
     $$ \sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)} $$
     correctly captures the trajectory without extraneous signs.

3. **Combining and Integrating:**  
   Multiply the simplified radical by $dy$:
   $$ \sqrt{\frac{y}{2a - y}} \, dy = \left(\frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta $$
   Recall the half-angle identity $2\sin^2\left(\frac{\theta}{2}\right) = 1 - \cos\theta$:
   $$ x = \int a(1 - \cos\theta) \, d\theta = a(\theta - \sin\theta) + C $$
   Applying the initial condition $x(0) = 0$ gives $C = 0$, recovering the cycloid parametric equations:
   $$ x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta) $$

#### Why That Substitution Works: The Hidden Circle

Taylor calls this an "unlikely looking substitution," but it is completely systematic.  
Rationalize the numerator of the integrand:
$$ \sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}} $$
Complete the square in the denominator:
$$ 2ay - y^2 = -(y^2 - 2ay + a^2) + a^2 = a^2 - (y - a)^2 $$
Now the integral becomes:
$$ \int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy $$

**Why This Is a Circle:**  
In the $(w, y)$ plane, the equation $w = \sqrt{a^2 - (y - a)^2}$ describes the boundary of a circle of radius $a$ centered at $(0, a)$:
$$ w^2 + (y - a)^2 = a^2 $$

**Why Two Different Types of $u$ Can Be Substituted:**  
Any expression involving $\sqrt{a^2 - u^2}$ naturally invites a circular parameterization, but we have two standard choices depending on the angle reference axis:
1. **The Sine Substitution ($u = a\sin\phi$):**  
   If we set $y - a = a\sin\phi$, then $y = a(1 + \sin\phi)$. Here the angle $\phi$ is measured relative to the horizontal diameter of the circle. At the release point ($y = 0$), this requires $\sin\phi = -1 \implies \phi = -\pi/2$. While mathematically valid, it introduces an awkward phase shift of $-\pi/2$ into the equations of motion.
2. **The Inverted Cosine Substitution ($u = -a\cos\theta$):**  
   If we instead set $y - a = -a\cos\theta$, then:
   $$ y = a(1 - \cos\theta) $$
   Here the angle $\theta$ is measured from the top apex of the circle. At $\theta = 0$, $\cos(0) = 1$, which gives $y = a(1 - 1) = 0$ automatically! Thus, the negative cosine choice is physically tailored to align $\theta = 0$ directly with the initial release point at the origin without requiring arbitrary phase angles.

#### The Algebraic Alternative: Direct Root Substitution (With Both Integration by Parts and Trig Methods)

You do not need to guess a trigonometric substitution. When faced with any rational function of a single linear radical $\sqrt{\frac{a y + b}{c y + d}}$, set the entire radical equal to a new algebraic variable $u$:
$$ u = \sqrt{\frac{y}{2a - y}} $$
Inverting for $y$:
$$ u^2 = \frac{y}{2a - y} \implies u^2(2a - y) = y \implies 2a u^2 = y(1 + u^2) \implies y = \frac{2a u^2}{1 + u^2} $$
Compute $dy$:
$$ dy = 2a \frac{d}{du}\left[1 - \frac{1}{1 + u^2}\right] du = \frac{4a u}{(1 + u^2)^2} \, du $$
Substitute into the integral $x = \int u \, dy$:
$$ x = \int u \cdot \frac{4a u}{(1 + u^2)^2} \, du = 4a \int \frac{u^2}{(1 + u^2)^2} \, du $$

We can solve this integral via two independent pathways:

##### Method A: Integration by Parts (Pure Algebraic Route)
Split the numerator as $u \cdot \frac{u}{(1+u^2)^2}$:
- Let $f = u \implies df = du$
- Let $dg = \frac{u}{(1+u^2)^2} \, du \implies g = -\frac{1}{2(1+u^2)}$

Applying $\int f \, dg = fg - \int g \, df$:
$$ \int \frac{u^2}{(1+u^2)^2} \, du = -\frac{u}{2(1+u^2)} + \frac{1}{2}\int \frac{du}{1+u^2} = -\frac{u}{2(1+u^2)} + \frac{1}{2}\arctan(u) $$
Multiplying by the overall factor $4a$:
$$ x(u) = 2a \arctan(u) - \frac{2a u}{1 + u^2} + C $$
Since $u = 0$ at $y = 0$, the boundary condition $x(0) = 0$ enforces $C = 0$.  
To interpret this geometrically, let $u = \tan\left(\frac{\theta}{2}\right)$. Then:
- $\arctan(u) = \frac{\theta}{2}$
- $\frac{2u}{1+u^2} = \frac{2\tan(\theta/2)}{1+\tan^2(\theta/2)} = \sin\theta$ (the standard double-angle identity)

Substituting these directly into $x(u)$:
$$ x(\theta) = 2a\left(\frac{\theta}{2}\right) - a\sin\theta = a(\theta - \sin\theta) $$
And for $y$:
$$ y = \frac{2a u^2}{1+u^2} = 2a\sin^2\left(\frac{\theta}{2}\right) = a(1 - \cos\theta) $$
This recovers the cycloid parametric equations without having to guess the substitution upfront!

##### Method B: Trigonometric Substitution
Setting $u = \tan\phi$, so $du = \sec^2\phi \, d\phi$:
$$ 4a \int \frac{\tan^2\phi}{(1+\tan^2\phi)^2} \sec^2\phi \, d\phi = 4a \int \frac{\tan^2\phi}{\sec^4\phi}\sec^2\phi \, d\phi = 4a \int \sin^2\phi \, d\phi $$
Using $\sin^2\phi = \frac{1 - \cos 2\phi}{2}$:
$$ 4a \int \left(\frac{1 - \cos 2\phi}{2}\right) d\phi = 2a\left(\phi - \frac{1}{2}\sin 2\phi\right) = 2a(\phi - \sin\phi\cos\phi) $$
Setting $\theta = 2\phi$ (so $\phi = \theta/2$), this immediately yields $x(\theta) = a(\theta - \sin\theta)$.

#### What $\theta$ Represents Physically

The parameter $\theta$ is the cumulative rotation angle (in radians) of the rolling circle that generates the curve:

```text
          x=0                         x = a*theta                      x = 2*pi*a
   y=0 ----*-------------------------------O-------------------------------*----> x
           |                              / \                              |
           |                             /   \                             |
           |                            /  a  \                            |
           |                           O-------* P(x,y)                    |
           |                            \ theta/                           |
           |                             \    /                            |
           |                              \  /                             |
           |                               \/                              |
           |                                                               |
           |                               . (Trough: theta = pi, y = 2a)  |
           v y
```

Imagine a circular disk of radius $a$ rolling without slipping along the underside of the horizontal axis ($y = 0$, pointing downward):
- **Center of the wheel:** As the wheel rolls through an angle $\theta$, its contact point has rolled a distance $a\theta$ along the rail:
  $$ (x_c, y_c) = (a\theta, a) $$
- **Point on the perimeter ($P$):** A marker fixed to the rim starts at the origin $(0, 0)$ when $\theta = 0$. After rotating clockwise by $\theta$, the marker's relative displacement from the wheel's center is:
  $$ \Delta x = -a\sin\theta, \quad \Delta y = -a\cos\theta $$
- **Absolute coordinates:** Combining center translation and rim rotation yields:
  $$ x(\theta) = x_c + \Delta x = a(\theta - \sin\theta) $$
  $$ y(\theta) = y_c + \Delta y = a(1 - \cos\theta) $$

$\theta$ also directly determines the local slope and launch angle of the path. Differentiating with respect to $\theta$:
$$ \frac{dy}{dx} = \frac{dy/d\theta}{dx/d\theta} = \frac{a\sin\theta}{a(1 - \cos\theta)} = \frac{2\sin(\theta/2)\cos(\theta/2)}{2\sin^2(\theta/2)} = \cot\left(\frac{\theta}{2}\right) $$
If $\psi$ is the inclination angle of the velocity vector relative to the horizontal ($\tan\psi = dy/dx$):
$$ \psi = \frac{\pi - \theta}{2} $$
- At $\theta \to 0$ (the start): $\psi = \pi/2$ (the path drops straight vertically).
- At $\theta = \pi$ (the trough): $\psi = 0$ (the trajectory is completely horizontal).
- At $\theta = 2\pi$ (the next cusp): $\psi = -\pi/2$ (the path rises back to vertical).

#### Why Assume the First Arch ($\theta \in [0, 2\pi]$) and $\sin(\theta/2) \ge 0$?

1. **The Mathematical Reason: Eliminating Absolute Value Signs**  
   The principal square root satisfies $\sqrt{u^2} = |u|$. In simplifying the radical:
   $$ \sqrt{\frac{y}{2a - y}} = \left| \tan\left(\frac{\theta}{2}\right) \right| = \frac{\left|\sin(\theta/2)\right|}{\left|\cos(\theta/2)\right|} $$
   If $\theta \in [0, 2\pi]$, then $\frac{\theta}{2} \in [0, \pi]$. Since sine is strictly non-negative on $[0, \pi]$:
   $$ \sin\left(\frac{\theta}{2}\right) \ge 0 \implies \left|\sin\left(\frac{\theta}{2}\right)\right| = \sin\left(\frac{\theta}{2}\right) $$
   This avoids carrying piece-wise $\pm$ absolute value signs.

2. **The Physical Reason: Geometry of the Fastest Path**  
   - **Energy Bounds:** Conservation of mechanical energy gives $v = \sqrt{2gy}$. At $y = 0$, speed is zero ($v = 0$). The particle cannot rise above $y = 0$, so it cannot continue past a cusp into negative $y$.
   - **Uniqueness:** A single arch ($\theta \in [0, 2\pi]$) starts at $(0, 0)$ and terminates at $(2\pi a, 0)$. By scaling the radius $a$, a single cycloid arch can pass through any target point $(x_2, y_2)$ in the lower half-plane ($x_2 > 0, y_2 \ge 0$).
   - **No Redundant Loops:** Any path extending past $\theta = 2\pi$ into a second arch would involve rising up to a cusp, stopping, and dropping into a new dip. That would add unnecessary path length and travel time, violating the time-minimization condition $\delta T = 0$.

#### Essential Mathematical Properties of Cycloids

- **Parametric Form:** $x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta)$
- **Differential Arc Length:**
  $$ ds = \sqrt{\dot{x}^2 + \dot{y}^2}\, d\theta = a\sqrt{(1-\cos\theta)^2 + \sin^2\theta}\, d\theta = 2a\sin\left(\frac{\theta}{2}\right) d\theta $$
- **Total Arc Length from Origin to $\theta$:**
  $$ s(\theta) = \int_0^\theta 2a\sin\left(\frac{\theta'}{2}\right) d\theta' = 4a\left(1 - \cos\left(\frac{\theta}{2}\right)\right) = 8a\sin^2\left(\frac{\theta}{4}\right) $$
  The total perimeter of one complete arch ($\theta = 2\pi$) is exactly $s_{\text{total}} = 8a$.
- **Radius of Curvature:**
  $$ \rho(\theta) = \frac{(\dot{x}^2 + \dot{y}^2)^{3/2}}{|\dot{x}\ddot{y} - \dot{y}\ddot{x}|} = 4a\sin\left(\frac{\theta}{2}\right) = \sqrt{8a y} $$
- **Self-Evolute Property:** The evolute (locus of centers of curvature) of a cycloid is an identical cycloid, shifted horizontally by $\pi a$ and vertically downward by $2a$.

## 6.4 More Than Two Variables

If the functional depends on multiple functions $y_1(x), y_2(x), \dots, y_n(x)$,
$$ S = \int_{x_1}^{x_2} f(y_1, \dots, y_n, y_1', \dots, y_n', x) \, dx $$
we can vary each function independently. This leads to a system of $n$ independent Euler-Lagrange equations:
$$ \frac{\partial f}{\partial y_i} - \frac{d}{dx} \frac{\partial f}{\partial y_i'} = 0 \quad \text{for } i = 1, 2, \dots, n $$

This extension is crucial for Lagrangian mechanics in 3D space, where we have coordinates $x(t), y(t), z(t)$, and time $t$ plays the role of the independent variable.

## Summary

The calculus of variations allows us to find stationary paths for functionals. The fundamental tool is the Euler-Lagrange equation, which converts a global variational problem into a local differential equation. This mathematical foundation is what allows us to formulate Lagrangian mechanics based on Hamilton's Principle of stationary action.
