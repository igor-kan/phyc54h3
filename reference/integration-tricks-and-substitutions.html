Step-by-Step Evaluation of Taylor’s Cycloid Substitution

The integral to evaluate from Equation (6.23) is: \[x = \int \sqrt{\frac{y}{2a - y}} \, dy\]

Taylor introduces the substitution: \[y = a(1 - \cos\theta)\]

1. Differential of the Substitution

Differentiating \(y\) with respect to \(\theta\): \[dy = \frac{d}{d\theta}\big[a(1 - \cos\theta)\big] d\theta = a\sin\theta \, d\theta\] Using the double-angle identity \(\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)\): \[dy = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\]

2. Simplifying the Radicand

Substitute \(y = a(1 - \cos\theta)\) into the numerator and denominator under the radical: Numerator: \[y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right)\] Denominator: \[2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right)\] Taking the ratio inside the square root: \[\frac{y}{2a - y} = \frac{2a\sin^2\left(\frac{\theta}{2}\right)}{2a\cos^2\left(\frac{\theta}{2}\right)} = \tan^2\left(\frac{\theta}{2}\right)\] Assuming the motion stays within the first arch (\(\theta \in [0, 2\pi]\) where \(\theta/2 \in [0, \pi]\) and \(\sin(\theta/2) \ge 0\)): \[\sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\]

3. Combining and Integrating

Multiply the simplified radical by \(dy\): \[\sqrt{\frac{y}{2a - y}} \, dy = \left(\frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta\] Recall the half-angle identity \(2\sin^2\left(\frac{\theta}{2}\right) = 1 - \cos\theta\): \[x = \int a(1 - \cos\theta) \, d\theta = a(\theta - \sin\theta) + C\] Applying the initial condition \(x(0) = 0\) gives \(C = 0\), recovering the cycloid parametric equations: \[x = a(\theta - \sin\theta), \quad y = a(1 - \cos\theta)\]

Why That Substitution Works: The Hidden Circle

Why That Substitution Works: The Hidden Circle

Taylor calls this an “unlikely looking substitution,” but it is completely systematic.
Rationalize the numerator of the integrand: \[ \sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}} \] Complete the square in the denominator: \[ 2ay - y^2 = -(y^2 - 2ay + a^2) + a^2 = a^2 - (y - a)^2 \] Now the integral becomes: \[ \int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy \]

Why This Is a Circle

In auxiliary coordinates \((w, y)\), the radical \(w = \sqrt{a^2 - (y - a)^2}\) describes the upper semicircle of: \[ w^2 + (y - a)^2 = a^2 \] which is a circle of radius \(a\) centered at \((w, y) = (0, a)\).

Why Two Different Types of \(u\) Can Be Substituted

Any integrand featuring \(\sqrt{a^2 - u^2}\) naturally invites a circular trigonometric substitution. However, there are two distinct ways to define the angular parameter:

  1. The Standard Sine Substitution (\(u = a\sin\phi\)):
    Setting \(y - a = a\sin\phi \implies y = a(1 + \sin\phi)\).
    Here, the angle \(\phi\) is referenced from the horizontal equator of the circle. At the release point (\(y = 0\)), we must have \(\sin\phi = -1 \implies \phi = -\pi/2\). While mathematically sound, this carries an unnecessary phase shift of \(-\pi/2\) into the final equations.

  2. The Inverted Cosine Substitution (\(u = -a\cos\theta\)):
    Setting \(y - a = -a\cos\theta \implies y = a(1 - \cos\theta)\).
    Here, the angle \(\theta\) is measured clockwise directly from the topmost vertical point (the cusp). At \(\theta = 0\), we have \(\cos(0) = 1 \implies y = a(1 - 1) = 0\). The initial release condition \(y(0) = 0\) is naturally satisfied with zero phase offset!

Both are valid circular parameterizations, but \(u = -a\cos\theta\) is chosen because it directly mirrors the physical launch boundary conditions.

The Algebraic Alternative: The Direct Root Substitution

You do not need to guess a trigonometric substitution. When faced with any rational function of a single linear radical \(\sqrt{\frac{a y + b}{c y + d}}\), set the entire radical equal to a new algebraic variable \(u\): \[ u = \sqrt{\frac{y}{2a - y}} \] Inverting for \(y\): \[ u^2 = \frac{y}{2a - y} \implies u^2(2a - y) = y \implies 2a u^2 = y(1 + u^2) \implies y = \frac{2a u^2}{1 + u^2} \] Compute \(dy\): \[ dy = 2a \frac{d}{du}\left[1 - \frac{1}{1 + u^2}\right] du = \frac{4a u}{(1 + u^2)^2} \, du \] Substitute into the integral \(x = \int u \, dy\): \[ x = \int u \cdot \frac{4a u}{(1 + u^2)^2} \, du = 4a \int \frac{u^2}{(1 + u^2)^2} \, du \]

To evaluate this integral without guessing parameters, we can use either integration by parts or a standard trigonometric substitution:

Method 1: Integration by Parts (Pure Algebraic Route)

Decompose the integrand as \(u \cdot \frac{u}{(1 + u^2)^2}\): - Let \(f = u \implies df = du\) - Let \(dg = \frac{u}{(1 + u^2)^2} \, du \implies g = -\frac{1}{2(1 + u^2)}\)

Applying \(\int f \, dg = fg - \int g \, df\): \[ \int \frac{u^2}{(1 + u^2)^2} \, du = -\frac{u}{2(1 + u^2)} + \frac{1}{2} \int \frac{du}{1 + u^2} = -\frac{u}{2(1 + u^2)} + \frac{1}{2}\arctan(u) \] Multiplying by the overall factor \(4a\): \[ x(u) = 2a\arctan(u) - \frac{2au}{1 + u^2} + C \] Using \(x(0) = 0\) at \(u = 0\), we have \(C = 0\).
Setting \(u = \tan(\theta/2)\), we observe: - \(\arctan(u) = \frac{\theta}{2}\) - \(\frac{2u}{1 + u^2} = \frac{2\tan(\theta/2)}{1 + \tan^2(\theta/2)} = \sin\theta\) (double-angle sine formula)

Substituting these gives: \[ x(\theta) = 2a\left(\frac{\theta}{2}\right) - a\sin\theta = a(\theta - \sin\theta) \] and: \[ y(\theta) = \frac{2a u^2}{1 + u^2} = 2a\sin^2\left(\frac{\theta}{2}\right) = a(1 - \cos\theta) \] This confirms the cycloid equations with zero guesswork!

Method 2: Standard Trigonometric Substitution

Let \(u = \tan\phi\), so \(du = \sec^2\phi \, d\phi\): \[ 4a \int \frac{\tan^2\phi}{(1 + \tan^2\phi)^2} \sec^2\phi \, d\phi = 4a \int \frac{\tan^2\phi}{\sec^4\phi}\sec^2\phi \, d\phi = 4a \int \sin^2\phi \, d\phi \] Using \(\sin^2\phi = \frac{1 - \cos 2\phi}{2}\): \[ 4a \int \left(\frac{1 - \cos 2\phi}{2}\right) d\phi = 2a\left(\phi - \frac{1}{2}\sin 2\phi\right) = 2a(\phi - \sin\phi\cos\phi) \] Setting \(\theta = 2\phi\), we immediately recover \(x = a(\theta - \sin\theta)\).

Derivation & Mechanics Insights for the Toolkit Patterns

  1. \(\sqrt{a^2 - x^2}\) (The Circle / Ellipse Pattern):
    • Origin: Comes from the Pythagorean identity \(x^2 + y^2 = a^2\).
    • Physics Use: Appears whenever potential energy is quadratic (\(U(x) = \frac{1}{2}kx^2\)), leading to velocity \(v(x) = \sqrt{\frac{2}{m}(E - \frac{1}{2}kx^2)} = \sqrt{\frac{k}{m}}\sqrt{A^2 - x^2}\). Integrating \(dt = dx/v\) gives \(t(x) = \sqrt{m/k}\arcsin(x/A)\), which inverts to pure harmonic oscillation \(x(t) = A\sin(\omega t)\).
  2. \(\sqrt{a^2 + x^2}\) (The Hyperbolic Sum Pattern):
    • Origin: Parameterizes the equilateral hyperbola \(y^2 - x^2 = a^2\) using \(y = a\cosh u, x = a\sinh u\).
    • Physics Use: In special relativity, relativistic velocity \(v\) and proper velocity \(w = \gamma v\) obey \(1 + (w/c)^2 = \gamma^2\). Integrating proper time \(d\tau = dt/\gamma = dt/\sqrt{1 + (w/c)^2}\) naturally invites \(w = c\sinh\eta\), where \(\eta\) is the relativistic rapidity.
  3. \(\sqrt{x^2 - a^2}\) (The Inverted Hyperbola Pattern):
    • Origin: Arises in Euler-Lagrange variational problems where \(f(y, y') = y\sqrt{1 + y'^2}\) (e.g. minimal surface of revolution, Taylor Problem 6.19).
    • Beltrami Identity: \(f - y'\frac{\partial f}{\partial y'} = \frac{y}{\sqrt{1 + y'^2}} = y_0 \implies y' = \frac{\sqrt{y^2 - y_0^2}}{y_0} \implies dx = \frac{y_0}{\sqrt{y^2 - y_0^2}} dy\).
    • Substitution: Setting \(y = y_0\cosh u\) gives \(dx = y_0 du \implies u = \frac{x - x_0}{y_0} \implies y(x) = y_0\cosh\left(\frac{x - x_0}{y_0}\right)\).
  4. \(\sqrt{\frac{a - x}{a + x}}\) (The Ratio Root Pattern):
    • Origin: By multiplying numerator and denominator by \(\sqrt{a - x}\), we get \(\frac{a - x}{\sqrt{a^2 - x^2}}\).
    • Trigonometric Rationale: The half-angle formula \(\tan^2\theta = \frac{1 - \cos 2\theta}{1 + \cos 2\theta}\) matches this ratio when \(x = a\cos(2\theta)\), collapsing the radical into a single trigonometric term \(\tan\theta\).
  5. \(\sqrt{\frac{x}{2a - x}}\) (The Cycloid / Half-Angle Ratio Pattern):
    • Origin: Rationalizing gives \(\frac{x}{\sqrt{2ax - x^2}} = \frac{x}{\sqrt{a^2 - (x - a)^2}}\).
    • Trigonometric Rationale & Algebraic Identity: This substitution perfectly neutralizes the fractional radical. Using \(x = a(1 - \cos\theta)\) (which is equivalent to \(2a\sin^2(\theta/2)\) by the half-angle formula), the denominator becomes \(2a - x = 2a - a(1 - \cos\theta) = a(1 + \cos\theta)\).
      Plugging these into the radical yields the ratio: \[ \frac{x}{2a - x} = \frac{a(1 - \cos\theta)}{a(1 + \cos\theta)} = \frac{1 - \cos\theta}{1 + \cos\theta} = \tan^2(\theta/2) \] Taking the square root simplifies the entire fractional expression to just \(\tan(\theta/2)\).
    • Differential: Differentiating the substitution yields \(dx = a\sin\theta\, d\theta\).
  6. \(\sqrt{(x - \alpha)(\beta - x)}\) (The Bound-State Turning Points Pattern):
    • Origin: In any 1D potential well \(U(x)\), classical turning points occur where \(E - U(x) = 0\). Near generic turning points, \(E - U(x) \approx k(x - \alpha)(\beta - x)\).
    • Factored Root Normalization: This substitution geometrically maps the linear span between the two roots \(\alpha\) and \(\beta\) to a unit trigonometric domain. By setting \(x = \alpha + (\beta - \alpha)\sin^2\theta\), we normalize the two factors inside the radical:
      1. The lower bound distance: \(x - \alpha = (\beta - \alpha)\sin^2\theta\)
      2. The upper bound distance: \(\beta - x = \beta - [\alpha + (\beta - \alpha)\sin^2\theta] = (\beta - \alpha)(1 - \sin^2\theta) = (\beta - \alpha)\cos^2\theta\) Multiplying them together inside the square root creates a perfect square: \[ \sqrt{(x - \alpha)(\beta - x)} = \sqrt{(\beta - \alpha)^2 \sin^2\theta \cos^2\theta} = (\beta - \alpha)\sin\theta\cos\theta \]
    • Differential: \(dx = 2(\beta - \alpha)\sin\theta\cos\theta\, d\theta\).
    • Result: This cleanly converts the radical, mapping \(x \in [\alpha, \beta]\) into \(\theta \in [0, \pi/2]\) and linearizing action-angle integrals \(\oint p\, dx = \pi(\beta - \alpha)^2/4\).

Advanced Integration Tricks for Variational Physics

1. Euler’s First and Third Substitutions for \(\sqrt{Ax^2 + Bx + C}\)

When quadratic radicands cannot be cleanly solved by simple trigonometric substitution or completing the square, Euler’s algebraic substitutions rationalize the integral by establishing a birational map between the conic \(Y^2 = Ax^2 + Bx + C\) and a parameter \(t\):

Euler’s First Substitution (\(A > 0\))

  • Condition: The leading coefficient \(A\) is positive.
  • Substitution: \[ \sqrt{Ax^2 + Bx + C} = \pm \sqrt{A}x + t \]
  • Derivation: Square both sides: \[ Ax^2 + Bx + C = Ax^2 \pm 2\sqrt{A}xt + t^2 \implies Bx + C = \pm 2\sqrt{A}xt + t^2 \] Notice that \(Ax^2\) cancels completely! Solving for \(x\) yields a purely rational expression in \(t\): \[ x = \frac{t^2 - C}{B \mp 2\sqrt{A}t} \] Both \(x\) and \(dx = \frac{d}{dt}\left[\frac{t^2 - C}{B \mp 2\sqrt{A}t}\right]dt\), as well as the radical itself, become rational functions of \(t\). The integral is completely solved by partial fractions.

Euler’s Third Substitution (Real Roots \(r_1, r_2\))

  • Condition: The quadratic factors over the reals as \(Ax^2 + Bx + C = A(x - r_1)(x - r_2)\).
  • Substitution: \[ \sqrt{A(x - r_1)(x - r_2)} = t(x - r_1) \]
  • Derivation: Square both sides: \[ A(x - r_1)(x - r_2) = t^2(x - r_1)^2 \] Divide by \((x - r_1)\): \[ A(x - r_2) = t^2(x - r_1) \implies Ax - A r_2 = t^2 x - t^2 r_1 \implies x = \frac{A r_2 - t^2 r_1}{A - t^2} \] The radical simplifies to \(t(x - r_1) = \frac{A(r_2 - r_1)t}{A - t^2}\), rendering the integrand completely rational in \(t\).

2. The Weierstrass Tangent Half-Angle Substitution

The Weierstrass substitution is known as the “universal trigonometric substitution.” It algebraically transforms any rational expression of \(\sin\theta\) and \(\cos\theta\) into a rational polynomial integral:

Geometric Origin

Consider the unit circle \(X^2 + Y^2 = 1\) parameterized by the angle \(\theta\) where \((X, Y) = (\cos\theta, \sin\theta)\). Draw a secant line from the fixed point \((-1, 0)\) through \((\cos\theta, \sin\theta)\) to the vertical line \(X = 0\). The slope of this line is: \[ t = \tan\left(\frac{\theta}{2}\right) \] By stereographic projection, every point on the unit circle corresponds to a unique real slope \(t \in (-\infty, \infty)\).

Algebraic Formulas

Using standard double-angle formulas with \(\tan(\theta/2) = t\): \[ \cos\theta = \cos^2\left(\frac{\theta}{2}\right) - \sin^2\left(\frac{\theta}{2}\right) = \frac{\cos^2(\theta/2) - \sin^2(\theta/2)}{\cos^2(\theta/2) + \sin^2(\theta/2)} = \frac{1 - t^2}{1 + t^2} \] \[ \sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) = \frac{2\sin(\theta/2)\cos(\theta/2)}{\cos^2(\theta/2) + \sin^2(\theta/2)} = \frac{2t}{1 + t^2} \] Differentiating \(\theta = 2\arctan(t)\): \[ d\theta = \frac{2}{1 + t^2} \, dt \]

Example

To evaluate \(\int \frac{d\theta}{2 + \cos\theta}\): \[ \int \frac{\frac{2\, dt}{1 + t^2}}{2 + \frac{1 - t^2}{1 + t^2}} = \int \frac{2\, dt}{2(1 + t^2) + (1 - t^2)} = \int \frac{2\, dt}{3 + t^2} = \frac{2}{\sqrt{3}}\arctan\left(\frac{t}{\sqrt{3}}\right) + C = \frac{2}{\sqrt{3}}\arctan\left(\frac{\tan(\theta/2)}{\sqrt{3}}\right) + C \]

3. Hyperbolic Conversions for Catenaries and Relativistic Rapidity

Whenever variational problems produce forms like \(\int \frac{dy}{\sqrt{y^2 - y_0^2}}\):

Why Hyperbolic Beats Trigonometric Secant

  • If you use trigonometric secant \(y = y_0\sec\theta\): \[ \int \frac{y_0\sec\theta\tan\theta}{\sqrt{y_0^2(\sec^2\theta - 1)}} \, d\theta = \int \sec\theta \, d\theta = \ln|\sec\theta + \tan\theta| + C = \ln\left|\frac{y + \sqrt{y^2 - y_0^2}}{y_0}\right| + C \] Inverting this logarithm to isolate \(y(x)\) requires exponentiation and solving quadratic equations with annoying sign choices.
  • Using hyperbolic cosine \(y = y_0\cosh u \implies dy = y_0\sinh u \, du\): \[ \int \frac{y_0\sinh u}{\sqrt{y_0^2(\cosh^2 u - 1)}} \, du = \int \frac{y_0\sinh u}{y_0\sinh u} \, du = \int du = u + C = \operatorname{arcosh}\left(\frac{y}{y_0}\right) + C \] Inverting this immediately gives: \[ y(x) = y_0\cosh\left(\frac{x - x_0}{y_0}\right) \] in a single clean step, eliminating absolute values and logarithms.

Application to Relativistic Rapidity

In special relativity, velocity addition is non-linear: \(v_{13} = \frac{v_{12} + v_{23}}{1 + v_{12}v_{23}/c^2}\).
By defining rapidity \(\eta = \operatorname{artanh}(v/c)\), velocity addition becomes strictly linear: \[ \eta_{13} = \eta_{12} + \eta_{23} \] The Lorentz factor becomes \(\gamma = \cosh\eta\), the momentum becomes \(p = mc\sinh\eta\), and the relativistic kinetic energy integral \(\int v\, dp = mc^2\int \tanh\eta\cosh\eta\, d\eta = mc^2\int \sinh\eta\, d\eta = mc^2(\cosh\eta - 1) = (\gamma - 1)mc^2\) is evaluated instantly.

Practice Problems for Speed Integration

Problem 1: The Normalized Fractional Root

\[\int_0^1 \sqrt{\frac{x}{1-x}} \, dx\]

Target Trick: The half-angle cycloid substitution (\(x = \sin^2\theta\)).

Speed-Round Solution: Let \(x = \sin^2\theta\), so \(dx = 2\sin\theta\cos\theta\, d\theta\). The bounds transform as \(0 \to 0\) and \(1 \to \pi/2\): \[\sqrt{\frac{x}{1-x}} = \sqrt{\frac{\sin^2\theta}{\cos^2\theta}} = \tan\theta\] Substitute directly into the integral: \[\int_0^{\pi/2} (\tan\theta) \cdot (2\sin\theta\cos\theta)\, d\theta = 2 \int_0^{\pi/2} \sin^2\theta\, d\theta\] Using the average value of \(\sin^2\theta\) over a quarter-period: \[2 \left(\frac{1}{2} \cdot \frac{\pi}{2}\right) = \mathbf{\frac{\pi}{2}}\]

Problem 2: The Factored Quadratic Surd

\[\int_0^1 \frac{dx}{(x+1)\sqrt{x(1-x)}}\]

Target Trick: Euler’s third substitution / factored root normalization.

Speed-Round Solution: Substitute \(x = \sin^2\theta\), giving \(dx = 2\sin\theta\cos\theta\, d\theta\) and \(\sqrt{x(1-x)} = \sin\theta\cos\theta\): \[\int_0^{\pi/2} \frac{2\sin\theta\cos\theta\, d\theta}{(1 + \sin^2\theta)\sin\theta\cos\theta} = \int_0^{\pi/2} \frac{2\, d\theta}{1 + \sin^2\theta}\] Divide numerator and denominator by \(\cos^2\theta\) to prepare an algebraic substitution: \[\int_0^{\pi/2} \frac{2\sec^2\theta}{\sec^2\theta + \tan^2\theta}\, d\theta = \int_0^{\pi/2} \frac{2\sec^2\theta}{1 + 2\tan^2\theta}\, d\theta\] Substitute \(u = \sqrt{2}\tan\theta\), so \(du = \sqrt{2}\sec^2\theta\, d\theta\), with limits \(0 \to \infty\): \[\int_0^\infty \frac{\sqrt{2}\, du}{1 + u^2} = \sqrt{2} \left[ \arctan(u) \right]_0^\infty = \sqrt{2}\left(\frac{\pi}{2}\right) = \mathbf{\frac{\pi}{\sqrt{2}}}\]

Problem 3: The 15-Second Weierstrass Benchmark

\[\int_0^{\pi/2} \frac{dx}{1 + \sin x + \cos x}\]

Target Trick: The classic half-angle substitution \(t = \tan(x/2)\).

Speed-Round Solution: Recall the rational identities: \[\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\, dt}{1+t^2}\] Combine the denominator terms: \[1 + \sin x + \cos x = \frac{(1+t^2) + 2t + (1-t^2)}{1+t^2} = \frac{2(1+t)}{1+t^2}\] The \((1+t^2)\) factors cancel against \(dx\): \[\int_0^1 \frac{\frac{2\, dt}{1+t^2}}{\frac{2(1+t)}{1+t^2}} = \int_0^1 \frac{dt}{1+t} = \left[ \ln(1+t) \right]_0^1 = \mathbf{\ln 2}\]

Problem 4: Inverse Factorization on \(\sqrt{x^2 - 1}\)

\[\int_1^2 \frac{\sqrt{x^2 - 1}}{x^4}\, dx\]

Target Trick: Direct radical factoring \(u = \sqrt{1 - x^{-2}}\) (bypassing trigonometric substitution).

Speed-Round Solution: Factor \(x\) out of the radical in the numerator: \[\frac{\sqrt{x^2-1}}{x^4} = \frac{x\sqrt{1 - x^{-2}}}{x^4} = \frac{\sqrt{1 - x^{-2}}}{x^3}\] Set \(u = \sqrt{1 - x^{-2}}\). Then \(u^2 = 1 - x^{-2} \implies 2u\, du = 2x^{-3}\, dx\), so: \[\frac{dx}{x^3} = u\, du\] The bounds transform from \(x \in [1, 2]\) to \(u \in \left[0, \frac{\sqrt{3}}{2}\right]\): \[\int_0^{\sqrt{3}/2} u \cdot (u\, du) = \int_0^{\sqrt{3}/2} u^2\, du = \left[ \frac{u^3}{3} \right]_0^{\sqrt{3}/2} = \frac{1}{3}\left(\frac{3\sqrt{3}}{8}\right) = \mathbf{\frac{\sqrt{3}}{8}}\]

Problem 5: Hyperbolic Shift with Inversion

\[\int_0^1 \frac{dx}{(x+1)\sqrt{x^2 + 2x + 2}}\]

Target Trick: Completing the square followed by inversion substitution \(u = 1/t\).

Speed-Round Solution: Complete the square inside the radical: \(x^2 + 2x + 2 = (x+1)^2 + 1\). Shift variables with \(y = x+1\): \[\int_1^2 \frac{dy}{y\sqrt{y^2 + 1}}\] Apply the inversion substitution \(y = \frac{1}{t}\), which gives \(dy = -\frac{dt}{t^2}\): \[\int_1^{1/2} \frac{-\frac{dt}{t^2}}{\frac{1}{t}\sqrt{\frac{1}{t^2} + 1}} = \int_{1/2}^1 \frac{dt}{\sqrt{1 + t^2}}\] Using the standard anti-derivative \(\int \frac{dt}{\sqrt{1+t^2}} = \operatorname{arsinh}(t) = \ln(t + \sqrt{t^2+1})\): \[\left[ \ln\left(t + \sqrt{t^2 + 1}\right) \right]_{1/2}^1 = \ln(1 + \sqrt{2}) - \ln\left(\frac{1 + \sqrt{5}}{2}\right) = \mathbf{\ln\left(\frac{2 + 2\sqrt{2}}{1 + \sqrt{5}}\right)}\]

Why Assume the First Arch (\(\theta \in [0, 2\pi]\)) and \(\sin(\theta/2) \ge 0\)?

1. The Mathematical Reason: Eliminating Absolute Value Signs

The substitution replaces \(\sqrt{y / (2a - y)}\) with trigonometric functions: \[\sqrt{\frac{y}{2a - y}} = \sqrt{\frac{2a\sin^2(\theta/2)}{2a\cos^2(\theta/2)}} = \sqrt{\tan^2\left(\frac{\theta}{2}\right)} = \left\vert{} \tan\left(\frac{\theta}{2}\right) \right\vert{} = \frac{\left\vert{}\sin(\theta/2)\right\vert{}}{\left\vert{}\cos(\theta/2)\right\vert{}}\] By definition, the principal square root \(\sqrt{u^2} = \vert{}u\vert{}\). If \(\theta \in [0, 2\pi]\), then the half-angle satisfies \(\frac{\theta}{2} \in [0, \pi]\). The sine function is strictly non-negative across the entire interval \([0, \pi]\): \[\sin\left(\frac{\theta}{2}\right) \ge 0 \implies \left\vert{}\sin\left(\frac{\theta}{2}\right)\right\vert{} = \sin\left(\frac{\theta}{2}\right)\] This ensures that the integrand evaluates to \(\sin(\theta/2)\) without carrying piece-wise \(\pm\) absolute value signs.

2. The Physical Reason: Geometry of the Fastest Path

  • Energy Bounds: Conservation of mechanical energy gives \(v = \sqrt{2gy}\). At \(y = 0\), speed is zero (\(v = 0\)). The particle cannot rise above \(y = 0\), which means it cannot continue past a cusp into negative \(y\).
  • Uniqueness: A single arch (\(\theta \in [0, 2\pi]\)) starts at \((0, 0)\) and terminates at \((2\pi a, 0)\). By scaling the radius \(a\), a single cycloid arch can pass through any target point \((x_2, y_2)\) in the lower half-plane (\(x_2 > 0, y_2 \ge 0\)).
  • No Redundant Loops: Any path extending past \(\theta = 2\pi\) into a second arch would involve rising up to a cusp, stopping, and dropping into a new dip. That would add unnecessary path length and travel time, violating the time-minimization condition \(\delta T = 0\).

Essential Mathematical Properties of Cycloids

Parametric Form: \[x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta)\]

Differential Arc Length: \[ds = \sqrt{\dot{x}^2 + \dot{y}^2}\, d\theta = a\sqrt{(1-\cos\theta)^2 + \sin^2\theta}\, d\theta = 2a\sin\left(\frac{\theta}{2}\right) d\theta\]

Total Arc Length from Origin to \(\theta\): \[s(\theta) = \int_0^\theta 2a\sin\left(\frac{\theta'}{2}\right) d\theta' = 4a\left(1 - \cos\left(\frac{\theta}{2}\right)\right) = 8a\sin^2\left(\frac{\theta}{4}\right)\]

The total perimeter of one complete arch (\(\theta = 2\pi\)) is exactly: \[s_{\text{total}} = 8a\]

Radius of Curvature: \[\rho(\theta) = \frac{(\dot{x}^2 + \dot{y}^2)^{3/2}}{\vert{}\dot{x}\ddot{y} - \dot{y}\ddot{x}\vert{}} = 4a\sin\left(\frac{\theta}{2}\right) = \sqrt{8a y}\]

Self-Evolute Property: The evolute (locus of centers of curvature) of a cycloid is an identical cycloid, shifted horizontally by \(\pi a\) and vertically downward by \(2a\).

# Step-by-Step Evaluation of Taylor's Cycloid Substitution

The integral to evaluate from Equation (6.23) is:
$$x = \int \sqrt{\frac{y}{2a - y}} \, dy$$

Taylor introduces the substitution:
$$y = a(1 - \cos\theta)$$

## 1. Differential of the Substitution
Differentiating $y$ with respect to $\theta$:
$$dy = \frac{d}{d\theta}\big[a(1 - \cos\theta)\big] d\theta = a\sin\theta \, d\theta$$
Using the double-angle identity $\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)$:
$$dy = 2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta$$

## 2. Simplifying the Radicand
Substitute $y = a(1 - \cos\theta)$ into the numerator and denominator under the radical:
Numerator:
$$y = a(1 - \cos\theta) = 2a\sin^2\left(\frac{\theta}{2}\right)$$
Denominator:
$$2a - y = 2a - a(1 - \cos\theta) = a(1 + \cos\theta) = 2a\cos^2\left(\frac{\theta}{2}\right)$$
Taking the ratio inside the square root:
$$\frac{y}{2a - y} = \frac{2a\sin^2\left(\frac{\theta}{2}\right)}{2a\cos^2\left(\frac{\theta}{2}\right)} = \tan^2\left(\frac{\theta}{2}\right)$$
Assuming the motion stays within the first arch ($\theta \in [0, 2\pi]$ where $\theta/2 \in [0, \pi]$ and $\sin(\theta/2) \ge 0$):
$$\sqrt{\frac{y}{2a - y}} = \tan\left(\frac{\theta}{2}\right) = \frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}$$

## 3. Combining and Integrating
Multiply the simplified radical by $dy$:
$$\sqrt{\frac{y}{2a - y}} \, dy = \left(\frac{\sin\left(\frac{\theta}{2}\right)}{\cos\left(\frac{\theta}{2}\right)}\right) \cdot \left[2a \sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) d\theta\right] = 2a \sin^2\left(\frac{\theta}{2}\right) d\theta$$
Recall the half-angle identity $2\sin^2\left(\frac{\theta}{2}\right) = 1 - \cos\theta$:
$$x = \int a(1 - \cos\theta) \, d\theta = a(\theta - \sin\theta) + C$$
Applying the initial condition $x(0) = 0$ gives $C = 0$, recovering the cycloid parametric equations:
$$x = a(\theta - \sin\theta), \quad y = a(1 - \cos\theta)$$

# Why That Substitution Works: The Hidden Circle

# Why That Substitution Works: The Hidden Circle

Taylor calls this an "unlikely looking substitution," but it is completely systematic.  
Rationalize the numerator of the integrand:
$$ \sqrt{\frac{y}{2a - y}} = \frac{y}{\sqrt{y(2a - y)}} = \frac{y}{\sqrt{2ay - y^2}} $$
Complete the square in the denominator:
$$ 2ay - y^2 = -(y^2 - 2ay + a^2) + a^2 = a^2 - (y - a)^2 $$
Now the integral becomes:
$$ \int \frac{y}{\sqrt{a^2 - (y - a)^2}} \, dy $$

### Why This Is a Circle
In auxiliary coordinates $(w, y)$, the radical $w = \sqrt{a^2 - (y - a)^2}$ describes the upper semicircle of:
$$ w^2 + (y - a)^2 = a^2 $$
which is a circle of radius $a$ centered at $(w, y) = (0, a)$.

### Why Two Different Types of $u$ Can Be Substituted
Any integrand featuring $\sqrt{a^2 - u^2}$ naturally invites a circular trigonometric substitution. However, there are two distinct ways to define the angular parameter:

1. **The Standard Sine Substitution ($u = a\sin\phi$):**  
   Setting $y - a = a\sin\phi \implies y = a(1 + \sin\phi)$.  
   Here, the angle $\phi$ is referenced from the horizontal equator of the circle. At the release point ($y = 0$), we must have $\sin\phi = -1 \implies \phi = -\pi/2$. While mathematically sound, this carries an unnecessary phase shift of $-\pi/2$ into the final equations.

2. **The Inverted Cosine Substitution ($u = -a\cos\theta$):**  
   Setting $y - a = -a\cos\theta \implies y = a(1 - \cos\theta)$.  
   Here, the angle $\theta$ is measured clockwise directly from the topmost vertical point (the cusp). At $\theta = 0$, we have $\cos(0) = 1 \implies y = a(1 - 1) = 0$. The initial release condition $y(0) = 0$ is naturally satisfied with zero phase offset!

Both are valid circular parameterizations, but $u = -a\cos\theta$ is chosen because it directly mirrors the physical launch boundary conditions.

# The Algebraic Alternative: The Direct Root Substitution

You do not need to guess a trigonometric substitution. When faced with any rational function of a single linear radical $\sqrt{\frac{a y + b}{c y + d}}$, set the entire radical equal to a new algebraic variable $u$:
$$ u = \sqrt{\frac{y}{2a - y}} $$
Inverting for $y$:
$$ u^2 = \frac{y}{2a - y} \implies u^2(2a - y) = y \implies 2a u^2 = y(1 + u^2) \implies y = \frac{2a u^2}{1 + u^2} $$
Compute $dy$:
$$ dy = 2a \frac{d}{du}\left[1 - \frac{1}{1 + u^2}\right] du = \frac{4a u}{(1 + u^2)^2} \, du $$
Substitute into the integral $x = \int u \, dy$:
$$ x = \int u \cdot \frac{4a u}{(1 + u^2)^2} \, du = 4a \int \frac{u^2}{(1 + u^2)^2} \, du $$

To evaluate this integral without guessing parameters, we can use either integration by parts or a standard trigonometric substitution:

### Method 1: Integration by Parts (Pure Algebraic Route)
Decompose the integrand as $u \cdot \frac{u}{(1 + u^2)^2}$:
- Let $f = u \implies df = du$
- Let $dg = \frac{u}{(1 + u^2)^2} \, du \implies g = -\frac{1}{2(1 + u^2)}$

Applying $\int f \, dg = fg - \int g \, df$:
$$ \int \frac{u^2}{(1 + u^2)^2} \, du = -\frac{u}{2(1 + u^2)} + \frac{1}{2} \int \frac{du}{1 + u^2} = -\frac{u}{2(1 + u^2)} + \frac{1}{2}\arctan(u) $$
Multiplying by the overall factor $4a$:
$$ x(u) = 2a\arctan(u) - \frac{2au}{1 + u^2} + C $$
Using $x(0) = 0$ at $u = 0$, we have $C = 0$.  
Setting $u = \tan(\theta/2)$, we observe:
- $\arctan(u) = \frac{\theta}{2}$
- $\frac{2u}{1 + u^2} = \frac{2\tan(\theta/2)}{1 + \tan^2(\theta/2)} = \sin\theta$ (double-angle sine formula)

Substituting these gives:
$$ x(\theta) = 2a\left(\frac{\theta}{2}\right) - a\sin\theta = a(\theta - \sin\theta) $$
and:
$$ y(\theta) = \frac{2a u^2}{1 + u^2} = 2a\sin^2\left(\frac{\theta}{2}\right) = a(1 - \cos\theta) $$
This confirms the cycloid equations with zero guesswork!

### Method 2: Standard Trigonometric Substitution
Let $u = \tan\phi$, so $du = \sec^2\phi \, d\phi$:
$$ 4a \int \frac{\tan^2\phi}{(1 + \tan^2\phi)^2} \sec^2\phi \, d\phi = 4a \int \frac{\tan^2\phi}{\sec^4\phi}\sec^2\phi \, d\phi = 4a \int \sin^2\phi \, d\phi $$
Using $\sin^2\phi = \frac{1 - \cos 2\phi}{2}$:
$$ 4a \int \left(\frac{1 - \cos 2\phi}{2}\right) d\phi = 2a\left(\phi - \frac{1}{2}\sin 2\phi\right) = 2a(\phi - \sin\phi\cos\phi) $$
Setting $\theta = 2\phi$, we immediately recover $x = a(\theta - \sin\theta)$.

### Derivation & Mechanics Insights for the Toolkit Patterns

1. **$\sqrt{a^2 - x^2}$ (The Circle / Ellipse Pattern):**  
   - **Origin:** Comes from the Pythagorean identity $x^2 + y^2 = a^2$.  
   - **Physics Use:** Appears whenever potential energy is quadratic ($U(x) = \frac{1}{2}kx^2$), leading to velocity $v(x) = \sqrt{\frac{2}{m}(E - \frac{1}{2}kx^2)} = \sqrt{\frac{k}{m}}\sqrt{A^2 - x^2}$. Integrating $dt = dx/v$ gives $t(x) = \sqrt{m/k}\arcsin(x/A)$, which inverts to pure harmonic oscillation $x(t) = A\sin(\omega t)$.

2. **$\sqrt{a^2 + x^2}$ (The Hyperbolic Sum Pattern):**  
   - **Origin:** Parameterizes the equilateral hyperbola $y^2 - x^2 = a^2$ using $y = a\cosh u, x = a\sinh u$.  
   - **Physics Use:** In special relativity, relativistic velocity $v$ and proper velocity $w = \gamma v$ obey $1 + (w/c)^2 = \gamma^2$. Integrating proper time $d\tau = dt/\gamma = dt/\sqrt{1 + (w/c)^2}$ naturally invites $w = c\sinh\eta$, where $\eta$ is the relativistic rapidity.

3. **$\sqrt{x^2 - a^2}$ (The Inverted Hyperbola Pattern):**  
   - **Origin:** Arises in Euler-Lagrange variational problems where $f(y, y') = y\sqrt{1 + y'^2}$ (e.g. minimal surface of revolution, Taylor Problem 6.19).  
   - **Beltrami Identity:** $f - y'\frac{\partial f}{\partial y'} = \frac{y}{\sqrt{1 + y'^2}} = y_0 \implies y' = \frac{\sqrt{y^2 - y_0^2}}{y_0} \implies dx = \frac{y_0}{\sqrt{y^2 - y_0^2}} dy$.  
   - **Substitution:** Setting $y = y_0\cosh u$ gives $dx = y_0 du \implies u = \frac{x - x_0}{y_0} \implies y(x) = y_0\cosh\left(\frac{x - x_0}{y_0}\right)$.

4. **$\sqrt{\frac{a - x}{a + x}}$ (The Ratio Root Pattern):**  
   - **Origin:** By multiplying numerator and denominator by $\sqrt{a - x}$, we get $\frac{a - x}{\sqrt{a^2 - x^2}}$.  
   - **Trigonometric Rationale:** The half-angle formula $\tan^2\theta = \frac{1 - \cos 2\theta}{1 + \cos 2\theta}$ matches this ratio when $x = a\cos(2\theta)$, collapsing the radical into a single trigonometric term $\tan\theta$.

5. **$\sqrt{\frac{x}{2a - x}}$ (The Cycloid / Half-Angle Ratio Pattern):**  
   - **Origin:** Rationalizing gives $\frac{x}{\sqrt{2ax - x^2}} = \frac{x}{\sqrt{a^2 - (x - a)^2}}$.  
   - **Trigonometric Rationale & Algebraic Identity:** This substitution perfectly neutralizes the fractional radical. Using $x = a(1 - \cos\theta)$ (which is equivalent to $2a\sin^2(\theta/2)$ by the half-angle formula), the denominator becomes $2a - x = 2a - a(1 - \cos\theta) = a(1 + \cos\theta)$.  
     Plugging these into the radical yields the ratio:
     $$ \frac{x}{2a - x} = \frac{a(1 - \cos\theta)}{a(1 + \cos\theta)} = \frac{1 - \cos\theta}{1 + \cos\theta} = \tan^2(\theta/2) $$
     Taking the square root simplifies the entire fractional expression to just $\tan(\theta/2)$.
   - **Differential:** Differentiating the substitution yields $dx = a\sin\theta\, d\theta$.

6. **$\sqrt{(x - \alpha)(\beta - x)}$ (The Bound-State Turning Points Pattern):**  
   - **Origin:** In any 1D potential well $U(x)$, classical turning points occur where $E - U(x) = 0$. Near generic turning points, $E - U(x) \approx k(x - \alpha)(\beta - x)$.  
   - **Factored Root Normalization:** This substitution geometrically maps the linear span between the two roots $\alpha$ and $\beta$ to a unit trigonometric domain. By setting $x = \alpha + (\beta - \alpha)\sin^2\theta$, we normalize the two factors inside the radical:
     1. The lower bound distance: $x - \alpha = (\beta - \alpha)\sin^2\theta$
     2. The upper bound distance: $\beta - x = \beta - [\alpha + (\beta - \alpha)\sin^2\theta] = (\beta - \alpha)(1 - \sin^2\theta) = (\beta - \alpha)\cos^2\theta$
     Multiplying them together inside the square root creates a perfect square:
     $$ \sqrt{(x - \alpha)(\beta - x)} = \sqrt{(\beta - \alpha)^2 \sin^2\theta \cos^2\theta} = (\beta - \alpha)\sin\theta\cos\theta $$
   - **Differential:** $dx = 2(\beta - \alpha)\sin\theta\cos\theta\, d\theta$.
   - **Result:** This cleanly converts the radical, mapping $x \in [\alpha, \beta]$ into $\theta \in [0, \pi/2]$ and linearizing action-angle integrals $\oint p\, dx = \pi(\beta - \alpha)^2/4$.

# Advanced Integration Tricks for Variational Physics

## 1. Euler's First and Third Substitutions for $\sqrt{Ax^2 + Bx + C}$

When quadratic radicands cannot be cleanly solved by simple trigonometric substitution or completing the square, **Euler's algebraic substitutions** rationalize the integral by establishing a birational map between the conic $Y^2 = Ax^2 + Bx + C$ and a parameter $t$:

### Euler's First Substitution ($A > 0$)
- **Condition:** The leading coefficient $A$ is positive.
- **Substitution:**
  $$ \sqrt{Ax^2 + Bx + C} = \pm \sqrt{A}x + t $$
- **Derivation:** Square both sides:
  $$ Ax^2 + Bx + C = Ax^2 \pm 2\sqrt{A}xt + t^2 \implies Bx + C = \pm 2\sqrt{A}xt + t^2 $$
  Notice that $Ax^2$ cancels completely! Solving for $x$ yields a purely rational expression in $t$:
  $$ x = \frac{t^2 - C}{B \mp 2\sqrt{A}t} $$
  Both $x$ and $dx = \frac{d}{dt}\left[\frac{t^2 - C}{B \mp 2\sqrt{A}t}\right]dt$, as well as the radical itself, become rational functions of $t$. The integral is completely solved by partial fractions.

### Euler's Third Substitution (Real Roots $r_1, r_2$)
- **Condition:** The quadratic factors over the reals as $Ax^2 + Bx + C = A(x - r_1)(x - r_2)$.
- **Substitution:**
  $$ \sqrt{A(x - r_1)(x - r_2)} = t(x - r_1) $$
- **Derivation:** Square both sides:
  $$ A(x - r_1)(x - r_2) = t^2(x - r_1)^2 $$
  Divide by $(x - r_1)$:
  $$ A(x - r_2) = t^2(x - r_1) \implies Ax - A r_2 = t^2 x - t^2 r_1 \implies x = \frac{A r_2 - t^2 r_1}{A - t^2} $$
  The radical simplifies to $t(x - r_1) = \frac{A(r_2 - r_1)t}{A - t^2}$, rendering the integrand completely rational in $t$.

## 2. The Weierstrass Tangent Half-Angle Substitution

The Weierstrass substitution is known as the "universal trigonometric substitution." It algebraically transforms any rational expression of $\sin\theta$ and $\cos\theta$ into a rational polynomial integral:

### Geometric Origin
Consider the unit circle $X^2 + Y^2 = 1$ parameterized by the angle $\theta$ where $(X, Y) = (\cos\theta, \sin\theta)$. Draw a secant line from the fixed point $(-1, 0)$ through $(\cos\theta, \sin\theta)$ to the vertical line $X = 0$. The slope of this line is:
$$ t = \tan\left(\frac{\theta}{2}\right) $$
By stereographic projection, every point on the unit circle corresponds to a unique real slope $t \in (-\infty, \infty)$.

### Algebraic Formulas
Using standard double-angle formulas with $\tan(\theta/2) = t$:
$$ \cos\theta = \cos^2\left(\frac{\theta}{2}\right) - \sin^2\left(\frac{\theta}{2}\right) = \frac{\cos^2(\theta/2) - \sin^2(\theta/2)}{\cos^2(\theta/2) + \sin^2(\theta/2)} = \frac{1 - t^2}{1 + t^2} $$
$$ \sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right) = \frac{2\sin(\theta/2)\cos(\theta/2)}{\cos^2(\theta/2) + \sin^2(\theta/2)} = \frac{2t}{1 + t^2} $$
Differentiating $\theta = 2\arctan(t)$:
$$ d\theta = \frac{2}{1 + t^2} \, dt $$

### Example
To evaluate $\int \frac{d\theta}{2 + \cos\theta}$:
$$ \int \frac{\frac{2\, dt}{1 + t^2}}{2 + \frac{1 - t^2}{1 + t^2}} = \int \frac{2\, dt}{2(1 + t^2) + (1 - t^2)} = \int \frac{2\, dt}{3 + t^2} = \frac{2}{\sqrt{3}}\arctan\left(\frac{t}{\sqrt{3}}\right) + C = \frac{2}{\sqrt{3}}\arctan\left(\frac{\tan(\theta/2)}{\sqrt{3}}\right) + C $$

## 3. Hyperbolic Conversions for Catenaries and Relativistic Rapidity

Whenever variational problems produce forms like $\int \frac{dy}{\sqrt{y^2 - y_0^2}}$:

### Why Hyperbolic Beats Trigonometric Secant
- If you use trigonometric secant $y = y_0\sec\theta$:
  $$ \int \frac{y_0\sec\theta\tan\theta}{\sqrt{y_0^2(\sec^2\theta - 1)}} \, d\theta = \int \sec\theta \, d\theta = \ln|\sec\theta + \tan\theta| + C = \ln\left|\frac{y + \sqrt{y^2 - y_0^2}}{y_0}\right| + C $$
  Inverting this logarithm to isolate $y(x)$ requires exponentiation and solving quadratic equations with annoying sign choices.
- Using hyperbolic cosine $y = y_0\cosh u \implies dy = y_0\sinh u \, du$:
  $$ \int \frac{y_0\sinh u}{\sqrt{y_0^2(\cosh^2 u - 1)}} \, du = \int \frac{y_0\sinh u}{y_0\sinh u} \, du = \int du = u + C = \operatorname{arcosh}\left(\frac{y}{y_0}\right) + C $$
  Inverting this immediately gives:
  $$ y(x) = y_0\cosh\left(\frac{x - x_0}{y_0}\right) $$
  in a single clean step, eliminating absolute values and logarithms.

### Application to Relativistic Rapidity
In special relativity, velocity addition is non-linear: $v_{13} = \frac{v_{12} + v_{23}}{1 + v_{12}v_{23}/c^2}$.  
By defining rapidity $\eta = \operatorname{artanh}(v/c)$, velocity addition becomes strictly linear:
$$ \eta_{13} = \eta_{12} + \eta_{23} $$
The Lorentz factor becomes $\gamma = \cosh\eta$, the momentum becomes $p = mc\sinh\eta$, and the relativistic kinetic energy integral $\int v\, dp = mc^2\int \tanh\eta\cosh\eta\, d\eta = mc^2\int \sinh\eta\, d\eta = mc^2(\cosh\eta - 1) = (\gamma - 1)mc^2$ is evaluated instantly.

# Practice Problems for Speed Integration

## Problem 1: The Normalized Fractional Root
$$\int_0^1 \sqrt{\frac{x}{1-x}} \, dx$$

**Target Trick:** The half-angle cycloid substitution ($x = \sin^2\theta$).

**Speed-Round Solution:**
Let $x = \sin^2\theta$, so $dx = 2\sin\theta\cos\theta\, d\theta$. The bounds transform as $0 \to 0$ and $1 \to \pi/2$:
$$\sqrt{\frac{x}{1-x}} = \sqrt{\frac{\sin^2\theta}{\cos^2\theta}} = \tan\theta$$
Substitute directly into the integral:
$$\int_0^{\pi/2} (\tan\theta) \cdot (2\sin\theta\cos\theta)\, d\theta = 2 \int_0^{\pi/2} \sin^2\theta\, d\theta$$
Using the average value of $\sin^2\theta$ over a quarter-period:
$$2 \left(\frac{1}{2} \cdot \frac{\pi}{2}\right) = \mathbf{\frac{\pi}{2}}$$

## Problem 2: The Factored Quadratic Surd
$$\int_0^1 \frac{dx}{(x+1)\sqrt{x(1-x)}}$$

**Target Trick:** Euler’s third substitution / factored root normalization.

**Speed-Round Solution:**
Substitute $x = \sin^2\theta$, giving $dx = 2\sin\theta\cos\theta\, d\theta$ and $\sqrt{x(1-x)} = \sin\theta\cos\theta$:
$$\int_0^{\pi/2} \frac{2\sin\theta\cos\theta\, d\theta}{(1 + \sin^2\theta)\sin\theta\cos\theta} = \int_0^{\pi/2} \frac{2\, d\theta}{1 + \sin^2\theta}$$
Divide numerator and denominator by $\cos^2\theta$ to prepare an algebraic substitution:
$$\int_0^{\pi/2} \frac{2\sec^2\theta}{\sec^2\theta + \tan^2\theta}\, d\theta = \int_0^{\pi/2} \frac{2\sec^2\theta}{1 + 2\tan^2\theta}\, d\theta$$
Substitute $u = \sqrt{2}\tan\theta$, so $du = \sqrt{2}\sec^2\theta\, d\theta$, with limits $0 \to \infty$:
$$\int_0^\infty \frac{\sqrt{2}\, du}{1 + u^2} = \sqrt{2} \left[ \arctan(u) \right]_0^\infty = \sqrt{2}\left(\frac{\pi}{2}\right) = \mathbf{\frac{\pi}{\sqrt{2}}}$$

## Problem 3: The 15-Second Weierstrass Benchmark
$$\int_0^{\pi/2} \frac{dx}{1 + \sin x + \cos x}$$

**Target Trick:** The classic half-angle substitution $t = \tan(x/2)$.

**Speed-Round Solution:**
Recall the rational identities:
$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\, dt}{1+t^2}$$
Combine the denominator terms:
$$1 + \sin x + \cos x = \frac{(1+t^2) + 2t + (1-t^2)}{1+t^2} = \frac{2(1+t)}{1+t^2}$$
The $(1+t^2)$ factors cancel against $dx$:
$$\int_0^1 \frac{\frac{2\, dt}{1+t^2}}{\frac{2(1+t)}{1+t^2}} = \int_0^1 \frac{dt}{1+t} = \left[ \ln(1+t) \right]_0^1 = \mathbf{\ln 2}$$

## Problem 4: Inverse Factorization on $\sqrt{x^2 - 1}$
$$\int_1^2 \frac{\sqrt{x^2 - 1}}{x^4}\, dx$$

**Target Trick:** Direct radical factoring $u = \sqrt{1 - x^{-2}}$ (bypassing trigonometric substitution).

**Speed-Round Solution:**
Factor $x$ out of the radical in the numerator:
$$\frac{\sqrt{x^2-1}}{x^4} = \frac{x\sqrt{1 - x^{-2}}}{x^4} = \frac{\sqrt{1 - x^{-2}}}{x^3}$$
Set $u = \sqrt{1 - x^{-2}}$. Then $u^2 = 1 - x^{-2} \implies 2u\, du = 2x^{-3}\, dx$, so:
$$\frac{dx}{x^3} = u\, du$$
The bounds transform from $x \in [1, 2]$ to $u \in \left[0, \frac{\sqrt{3}}{2}\right]$:
$$\int_0^{\sqrt{3}/2} u \cdot (u\, du) = \int_0^{\sqrt{3}/2} u^2\, du = \left[ \frac{u^3}{3} \right]_0^{\sqrt{3}/2} = \frac{1}{3}\left(\frac{3\sqrt{3}}{8}\right) = \mathbf{\frac{\sqrt{3}}{8}}$$

## Problem 5: Hyperbolic Shift with Inversion
$$\int_0^1 \frac{dx}{(x+1)\sqrt{x^2 + 2x + 2}}$$

**Target Trick:** Completing the square followed by inversion substitution $u = 1/t$.

**Speed-Round Solution:**
Complete the square inside the radical: $x^2 + 2x + 2 = (x+1)^2 + 1$. Shift variables with $y = x+1$:
$$\int_1^2 \frac{dy}{y\sqrt{y^2 + 1}}$$
Apply the inversion substitution $y = \frac{1}{t}$, which gives $dy = -\frac{dt}{t^2}$:
$$\int_1^{1/2} \frac{-\frac{dt}{t^2}}{\frac{1}{t}\sqrt{\frac{1}{t^2} + 1}} = \int_{1/2}^1 \frac{dt}{\sqrt{1 + t^2}}$$
Using the standard anti-derivative $\int \frac{dt}{\sqrt{1+t^2}} = \operatorname{arsinh}(t) = \ln(t + \sqrt{t^2+1})$:
$$\left[ \ln\left(t + \sqrt{t^2 + 1}\right) \right]_{1/2}^1 = \ln(1 + \sqrt{2}) - \ln\left(\frac{1 + \sqrt{5}}{2}\right) = \mathbf{\ln\left(\frac{2 + 2\sqrt{2}}{1 + \sqrt{5}}\right)}$$

# Appendix: The Cycloid Substitution Details

## What $\theta$ Represents Physically
The parameter $\theta$ is the cumulative rotation angle (in radians) of the rolling circle that generates the curve.

```text
          x=0                         x = a*theta                      x = 2*pi*a
   y=0 ----*-------------------------------O-------------------------------*----> x
           |                              / \                              |
           |                             /   \                             |
           |                            /  a  \                            |
           |                           O-------* P(x,y)                    |
           |                            \ theta/                           |
           |                             \    /                            |
           |                              \  /                             |
           |                               \/                              |
           |                                                               |
           |                               . (Trough: theta = pi, y = 2a)  |
           v y
```

Imagine a circular disk of radius $a$ rolling without slipping along the underside of the horizontal axis ($y = 0$, pointing downward):

**Center of the wheel:** As the wheel rolls through an angle $\theta$, its contact point has rolled a distance $a\theta$ along the rail. The center of the disk is located at:
$$(x_c, y_c) = (a\theta, a)$$

**Point on the perimeter ($P$):** A marker fixed to the rim starts at the origin $(0, 0)$ when $\theta = 0$. After rotating clockwise by $\theta$, the marker's relative displacement from the wheel's center is:
$$\Delta x = -a\sin\theta, \quad \Delta y = -a\cos\theta$$

**Absolute coordinates:** Combining center translation and rim rotation yields the parametric equations:
$$x(\theta) = x_c + \Delta x = a(\theta - \sin\theta)$$
$$y(\theta) = y_c + \Delta y = a(1 - \cos\theta)$$

$\theta$ also directly determines the local slope and launch angle of the path. Differentiating with respect to $\theta$:
$$\frac{dy}{dx} = \frac{dy/d\theta}{dx/d\theta} = \frac{a\sin\theta}{a(1 - \cos\theta)} = \frac{2\sin(\theta/2)\cos(\theta/2)}{2\sin^2(\theta/2)} = \cot\left(\frac{\theta}{2}\right)$$

If $\psi$ is the inclination angle of the velocity vector relative to the horizontal ($\tan\psi = dy/dx$):
$$\psi = \frac{\pi - \theta}{2}$$
- **At $\theta \to 0$ (the start):** $\psi = \pi/2$ (the path drops straight vertically).
- **At $\theta = \pi$ (the trough):** $\psi = 0$ (the trajectory is completely horizontal).
- **At $\theta = 2\pi$ (the next cusp):** $\psi = -\pi/2$ (the path rises back to vertical).

## Why Assume the First Arch ($\theta \in [0, 2\pi]$) and $\sin(\theta/2) \ge 0$?

### 1. The Mathematical Reason: Eliminating Absolute Value Signs
The substitution replaces $\sqrt{y / (2a - y)}$ with trigonometric functions:
$$\sqrt{\frac{y}{2a - y}} = \sqrt{\frac{2a\sin^2(\theta/2)}{2a\cos^2(\theta/2)}} = \sqrt{\tan^2\left(\frac{\theta}{2}\right)} = \left\vert{} \tan\left(\frac{\theta}{2}\right) \right\vert{} = \frac{\left\vert{}\sin(\theta/2)\right\vert{}}{\left\vert{}\cos(\theta/2)\right\vert{}}$$
By definition, the principal square root $\sqrt{u^2} = \vert{}u\vert{}$. If $\theta \in [0, 2\pi]$, then the half-angle satisfies $\frac{\theta}{2} \in [0, \pi]$.
The sine function is strictly non-negative across the entire interval $[0, \pi]$:
$$\sin\left(\frac{\theta}{2}\right) \ge 0 \implies \left\vert{}\sin\left(\frac{\theta}{2}\right)\right\vert{} = \sin\left(\frac{\theta}{2}\right)$$
This ensures that the integrand evaluates to $\sin(\theta/2)$ without carrying piece-wise $\pm$ absolute value signs.

### 2. The Physical Reason: Geometry of the Fastest Path
- **Energy Bounds:** Conservation of mechanical energy gives $v = \sqrt{2gy}$. At $y = 0$, speed is zero ($v = 0$). The particle cannot rise above $y = 0$, which means it cannot continue past a cusp into negative $y$.
- **Uniqueness:** A single arch ($\theta \in [0, 2\pi]$) starts at $(0, 0)$ and terminates at $(2\pi a, 0)$. By scaling the radius $a$, a single cycloid arch can pass through any target point $(x_2, y_2)$ in the lower half-plane ($x_2 > 0, y_2 \ge 0$).
- **No Redundant Loops:** Any path extending past $\theta = 2\pi$ into a second arch would involve rising up to a cusp, stopping, and dropping into a new dip. That would add unnecessary path length and travel time, violating the time-minimization condition $\delta T = 0$.

## Essential Mathematical Properties of Cycloids

**Parametric Form:**
$$x(\theta) = a(\theta - \sin\theta), \quad y(\theta) = a(1 - \cos\theta)$$

**Differential Arc Length:**
$$ds = \sqrt{\dot{x}^2 + \dot{y}^2}\, d\theta = a\sqrt{(1-\cos\theta)^2 + \sin^2\theta}\, d\theta = 2a\sin\left(\frac{\theta}{2}\right) d\theta$$

**Total Arc Length from Origin to $\theta$:**
$$s(\theta) = \int_0^\theta 2a\sin\left(\frac{\theta'}{2}\right) d\theta' = 4a\left(1 - \cos\left(\frac{\theta}{2}\right)\right) = 8a\sin^2\left(\frac{\theta}{4}\right)$$

The total perimeter of one complete arch ($\theta = 2\pi$) is exactly:
$$s_{\text{total}} = 8a$$

**Radius of Curvature:**
$$\rho(\theta) = \frac{(\dot{x}^2 + \dot{y}^2)^{3/2}}{\vert{}\dot{x}\ddot{y} - \dot{y}\ddot{x}\vert{}} = 4a\sin\left(\frac{\theta}{2}\right) = \sqrt{8a y}$$

**Self-Evolute Property:**
The evolute (locus of centers of curvature) of a cycloid is an identical cycloid, shifted horizontally by $\pi a$ and vertically downward by $2a$.
